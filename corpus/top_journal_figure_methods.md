# Nature 等顶刊论文绘图源码方法库

## 范围与证据

本报告聚焦能够从论文 DOI 追溯到公开代码仓库、再追溯到具体图号脚本或 notebook 的案例。论文元数据由 Crossref 或 DOI 页面核验；仓库固定到 `corpus/top_journal_figure_code_index.csv` 中的 commit。星数仅记录 2026-08-03 的快照，不作为质量判据。

证据等级：

- `A`：论文、仓库和具体绘图文件可以互相对应，且仓库有明确许可证。
- `A-index-only`：对应关系可以核验，但仓库未声明许可证；只学习思想并保存链接，不复制或再分发源码。

## 源码中反复出现的高价值方法

### 1. 一张图只维护一条主证据链

顶刊源码通常按图号拆目录或脚本，而不是用一个巨型 notebook 生成所有图片。正文主图、稳健性、运行时间和补充诊断分别维护。数模工作台应延续这一做法：每张图绑定一个 Figure Contract、一个输入产物和一个生成入口。

### 2. 预测图使用中心线、区间带和事件标记三层结构

`us-htf-projections` 用 10% 与 90% 分位数围成不确定性带，以 50% 分位数作为主线，再叠加阈值年份或事件标记。三层分别回答“可能范围”“典型轨迹”“决策时点”。

迁移到数模竞赛：预测题不要只画一条拟合曲线。至少给出中心预测、区间含义和关键阈值；图注明确区间是分位数、置信区间、预测区间还是均值加减标准差，不能混写。

### 3. 多目标比较把基线和中位参考线画进坐标系

`scib-reproducibility` 将两个目标放在横纵轴，用颜色表示方法、点大小表示总分、形状表示输出类型，并叠加未处理基线与样本中位数参考线。分面保持固定纵横比，使不同数据集可以直接比较。

迁移到数模竞赛：多目标优化优先使用“目标 1 对目标 2”的散点或 Pareto 图。把原方案、可行边界、中位水平和推荐解直接画出；颜色之外再用形状、边框或点大小编码。

### 4. 稳健性矩阵必须共享色标范围

`cellrank_reproducibility` 先跨参数实验计算统一 `vmin/vmax`，再绘制共享行列轴的相关矩阵；色条和标题只在首列或首行出现。这样颜色差异才是数值差异，而不是每个面板独立归一化造成的视觉假象。

迁移到数模竞赛：灵敏度热力图、相关矩阵和情景矩阵必须统一范围。若不同指标量纲确实不同，应分组或标准化，并在图注写明标准化方式。

### 5. 空间问题同时保留原始空间和聚合关系

`squidpy_reproducibility` 将空间点位图与邻域富集热力图、共现曲线分开绘制。前者回答“对象在哪里”，后者回答“关系是否稳定存在”。它还固定聚类方法、色标范围和色条标签。

迁移到数模竞赛：路径规划、设施选址、区域风险和网络题不要只给地图。至少再给一张距离、流量、邻接、共现或区域统计图，用于解释空间格局背后的数量关系。

### 6. 模型诊断、校准和计算成本分图表达

`totalVI_reproducibility` 将后验预测误差、校准误差和运行时间拆成独立图。源码明确设置可编辑字体输出：`pdf.fonttype = 42`、`svg.fonttype = none`，并保存紧边界 PDF。

迁移到数模竞赛：预测精度、校准、残差、运行时间和内存不是同一结论。主文保留最关键的一到两张，其他放附录；不要用训练损失或收敛曲线代替泛化误差和校准。

### 7. 密集数据层可栅格化，文字和坐标轴保持矢量

`multifeature_integration_paper` 对密集热力图、3D 点云和神经结构层使用选择性 `rasterized=True`，但保留坐标轴、文字和标注为矢量。这能显著降低 PDF 大小，同时避免整张图片变成模糊位图。

迁移到数模竞赛：超过数万点的散点、网格或地图底层可在 300--600 dpi 栅格化，再嵌入 PDF/SVG 容器。最终必须在论文插入尺寸下检查点密度、文字清晰度和文件大小。

### 8. 用描边、层级和直接标注处理曲线遮挡

南极海冰源码先画更粗的白色底线，再叠加黑色或红色主线，并用 `zorder` 控制观测线位于最上层。它同时固定跨曲线的语义颜色：高分辨率为黑灰、低分辨率为青绿、观测为红色。

迁移到数模竞赛：密集背景上的关键曲线可以使用浅色描边或半透明背景带。颜色语义应跨图保持一致，但红色只用于风险、违规或关键观测，避免所有主线都使用高饱和色。

### 9. 小多图只保留一个共享图例或色条

洪水预测代码仅在第一个面板显示图例；CellRank 仅在首面板显示色条；多个仓库使用共享坐标轴和固定间距。这样能够把视觉预算留给数据而不是重复说明。

迁移到数模竞赛：小多图共享刻度、图例、色条和单位。只有数据范围确实不同且比较不是目标时，才允许独立坐标范围。

### 10. 理论变量与物理变量可以采用成对视图

微生物温度源码把模型使用的变换坐标和物理温度视图配对，并复用同一图例。动力系统源码将特征根平面、模态振幅、不同模态数的拟合优度和时间演化拆成连续证据链。

迁移到数模竞赛：如果模型在对数、标准化或倒数尺度上求解，正文应同时给出可解释的原始量视图，或提供清晰的轴变换说明。不要让读者只看到算法坐标而无法理解实际意义。

## 面向数学建模竞赛的四套推荐图组

### 预测与风险

1. 历史数据、基线和中心预测。
2. 分位数或预测区间带。
3. 阈值、拐点或首次越界时刻。
4. 不同地区或情景采用共享尺度小多图。

### 多目标优化与决策

1. 目标 1 对目标 2 的散点或 Pareto 前沿。
2. 原方案、约束边界和推荐解直接标注。
3. 点大小承载综合评分，形状承载算法或方案类型。
4. 另给三线表报告精确决策变量与目标值。

### 灵敏度与稳健性

1. 参数-输出曲线标出基准点。
2. 多参数实验使用共享色标矩阵。
3. 不同随机种子或样本扰动报告区间而非单次结果。
4. 收敛曲线只作为算法诊断，不作为模型有效性的唯一证据。

### 空间、网络与路径

1. 原始地理或网络结构图。
2. 关键路径、设施或风险区域高亮。
3. 邻接、流量、距离或共现矩阵解释关系。
4. 区域级统计或情景差值图解释决策后果。

## 导出与复用边界

- 优先输出 PDF/SVG，并保留可编辑文字；PNG 作为 300--600 dpi 兼容件。
- Python PDF 建议使用 TrueType 字体嵌入；密集图层可选择性栅格化。
- 公开源码中的配色和布局可以学习，但不应机械复刻论文整图。
- MIT、BSD、AGPL 等代码的复用必须遵守各自许可证；`NOASSERTION` 仓库仅保留索引与抽象经验。
- 顶刊发表不等于图形方法对当前题目必然适用。最终图型仍由 Figure Contract、证据类型和国赛页面预算决定。
