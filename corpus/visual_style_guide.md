# 数学建模论文排版与绘图准则

本准则来自 2024-2025 CUMCM 官方展示论文 23 篇的全量页面缓存、版式指标和关键页视觉复核，其中 17 篇本轮完成摘要/框架/主结果/验证锚点卡片，6 篇此前完成精读。它总结可迁移做法，也明确记录官方展示论文中不应照搬的细节。页码均指 corpus/raw/<paper-id>/page-XX.jpg 的展示页码。

## 1. 页面与文字层级

- 摘要独立成页，标题、摘要标题、正文、关键词形成四级层次。23篇全量页面中均观察到这一首屏模式。
- 摘要按子问题逐段写，每段固定为“问题目标 -> 模型/算法 -> 关键数值 -> 解释”。C038 第1页的信息密度最佳；B159 第1页也给出利润数值。A163 的方法完整，但关键数值不足。
- 正文保持单栏。样本的中位左右留白约为页面宽度的 12%-15%，图表以通栏为主。
- 一级标题必须承担导航功能。不要为了压页数缩小章节间距到难以扫描。
- 2026 国赛正文不超过30页。C038 缓存到展示第33页仍在展开第三问，因此它的章节深度可以学，篇幅不能学。

推荐正文视觉规格：

| 元素 | 建议 |
|---|---|
| 正文 | 宋体小四，1.2-1.3倍行距 |
| 一级标题 | 黑体三号或小三，段前明显留白 |
| 二级标题 | 黑体四号，编号和标题同一行 |
| 图内文字 | 最终插入尺寸下不小于正文的80% |
| 图注 | 图下方居中，描述结论或对象，不写“结果图” |
| 表题 | 表上方居中，单位放表头或表下注 |

## 2. 摘要页的高分结构

摘要页先服务评委快速判断，不服务背景铺垫。

1. 首段用2-3句说明问题、数据和模型组合。
2. 每个子问题单独一段，必须至少出现一个模型名和一个结果数值。
3. 最后一段给误差、灵敏度或风险情景结果。
4. 关键词3-5个，优先写模型、问题类型和验证方法。

从样本得到的直接证据：

- A196 第1页把五问的遮蔽时长、投放参数和网格/差分进化误差放在同一页，结果可直接核验。
- C132 第1页将 ICC `74.3%`、预测精度 `94.7%` 和分类准确率 `99.7%` 与对应模型绑定。
- C038 第1页同时报告 `21533950.7`、`17925814.6`、`17098212.4` 等收益结果，读者无需翻正文即可判断模型产出。
- B159 第1页把问题三最优期望利润 `56.7` 元和问题四修正后的 `54.2` 元放入摘要，形成基准与稳健性对照。
- E010 第1页报告聚类比例 `29:70:20` 和优化平均车速 `50.35 km/h`，模型结果与业务意义同时出现。

## 3. 整体框架图

总框架图应回答三件事：每问输入什么、建立什么模型、输出如何流向下一问。

- 递进型问题参考 C038 第3页和 A196 第3页；前者表现风险模型递进，后者表现单机单弹、时空优化和多机多弹的任务递进。
- 多模块统计题参考 C132 第4页四色四象限框架，每个区块都要写清输入、模型和输出。
- 分支判断参考 E010 第12页；菱形只用于真分支，回路必须闭合。
- 简单层级参考 B159 第3页；当关系只有“零件 -> 半成品 -> 成品”时，不必做复杂装饰。

固定规则：

- 输入用浅黄，数据处理用浅蓝，模型用浅绿，风险或失败状态用低饱和红。
- 颜色之外再用边框、线型或节点形状编码，保证黑白打印可读。
- 单个框不超过两行；流程图中的模型名应与章节标题和代码函数名完全一致。
- 导出 SVG/PDF，不使用截图。

## 4. 数据图的证据角色

每张图只能承担一种主要角色，并在图注或正文中明确结论。

| 角色 | 推荐图型 | 样本证据 | 迁移要求 |
|---|---|---|---|
| 问题抽象 | 几何示意、拓扑、地图 | A163第4页；E010第19页 | 标注变量、方向和单位 |
| EDA | 小多图、排序条形图 | E010第7页；C038第7页 | 共享坐标轴，类别先排序 |
| 主结果 | 方案热力图、图加表 | C038第21页；A163第26页 | 图看模式，表给精确值 |
| 算法诊断 | 收敛曲线 | C038第23/32页；E010第18页 | 多随机种子给均值和波动带 |
| 灵敏度 | 参数-输出曲线、龙卷风图 | B159第22页 | 标注基准点、变化范围和效应量 |
| 稳健性 | 同尺度情景对比 | C038第31/32页 | 画差值或风险-收益前沿 |
| 模型假设 | Q-Q、残差-拟合值、LOWESS | C132第13-14页 | 每幅诊断后明确通过、偏离和适用边界 |
| 决策阈值 | 响应曲线加风险区和竖线 | C132第24页 | 同时标安全区、阈值、群体和性能要求 |

## 5. 配色与线型

- 同一对象跨图保持同色。A163 的橙色板凳和浅蓝参考轨迹是最稳定的对象编码。
- 二情景比较使用蓝 `#4472C4` 与橙 `#ED7D31`，同时用实线/虚线或圆点/三角标记。
- 三类别可以使用蓝、橙、青绿，避免红绿直接对比。
- 红色只用于风险、约束违反或下降；绿色只用于可行、改善或通过。
- 连续变量使用单调色带；相关性使用以0为中心的发散色带。
- 不使用彩虹色带。热力图需要明确色条标题、单位、缺失值颜色和零值颜色。

## 6. 表格

样本中决策表很重要，但多篇2024论文使用全网格。工作台默认采用 A196 第24页和 C132 第24页那样的三线表：

- 数字按小数点对齐，单位只在表头出现一次。
- 仅用浅灰行底或粗体标关键结果；若用黄色标最优，必须再加粗或符号，避免颜色成为唯一信号。
- 决策矩阵先排序或分组。B159 第13页“16方案乘6情景”的结构值得复用，网格和纯黄色编码不照搬。
- 大表只留能支持结论的列；完整结果放支撑材料。

## 7. 多面板与高密度图

- 多面板统一坐标、图例和字体。E010 第7页的四周小多图结构正确，但每幅曲线过多；应只保留均值、工作日带和周末带。
- 单幅图超过4条曲线时，优先分面或突出1-2条主线，其余线设为浅灰。
- 横轴类别超过20个时，改为水平排序条形图、热力图或只展示Top-K。
- C038 第21页和E010第25页证明“能放下一页”不等于“能读懂”。标签不可读时必须重构图型。

## 8. 明确禁止的做法

- 不截取绘图窗口、终端或Excel界面。E010 第18和25页的截图只能当负面样例。
- 不保留 `1e6`、`1e7` 等软件默认记号；改成“利润（百万元）”或在轴上标 `×10^6`。
- 不使用 `alpha`、`beta` 这类未解释的默认轴名；写成论文符号及中文含义。
- 不让图注断成孤字。A163 第13页并排图需要为图注设定最小宽度或改用 `(a)(b)` 总图注。
- 不用收敛曲线代替模型验证；至少再给基线、误差、灵敏度或风险情景中的一项。
- 不用一张相关热力图代替统计诊断。C132 第13-14页展示了从正态性、同方差到非线性偏差的完整检查。
- 不用颜色作为唯一编码，不在正文插入低分辨率截图。

## 9. 赛场出图检查单

每张图导出前确认：

- 一句话能说清它支持哪个结论。
- 坐标轴有变量名和单位，字号在最终版PDF中可读。
- 图例不遮挡数据，且不超过6项。
- 黑白打印仍能区分系列。
- 图在正文中先被引用，再出现。
- 图注包含对象、条件和比较关系。
- 数字能追溯到实验文件，不在绘图代码中手填。
- 同时导出 PDF/SVG 和 300-600 dpi PNG。

完整逐图记录见 corpus/figure_inventory.csv，页面总览见 corpus/rendered/。

## 10. 17篇目标语料的证据边界

- 每篇卡片至少绑定第1页摘要、第2页问题分析、第4页符号/框架、第7页主结果和第10页验证锚点；页码、文件名和观察写在 corpus/cards/*.json。
- 页面图片已逐页 SHA-256 校验并记录覆盖率；卡片将“页面中可见的模型类别”与“未能由低分辨率图像确认的精确算法名”分开。
- 官方展示页的水印、压缩和网页缩放不属于原论文排版规则；正式论文应以 XeLaTeX 生成的 PDF 和渲染页为准。
- 目标语料的统一规律是“摘要按子问给方法与结果、流程图/符号表先于公式、主图与短表配对、验证至少包含基线/误差/情景之一”。
