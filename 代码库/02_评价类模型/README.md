# 02 评价与排序模型

> 本目录用于多指标评价、排序和效率比较的候选方法学习。高质量评价的核心不是“组合更多方法”，而是**指标定义、方向、尺度、权重来源和排名稳定性**。

## 先做什么

1. 明确评价对象和最终排序/分级用途；
2. 为每个指标写清含义、单位、正/负向和重复信息；
3. 建立 **equal-weight 或简单业务规则 baseline**；
4. 再选择与权重信息和决策目标匹配的方法；
5. 最后做权重扰动、删指标和排名稳定性。

## 选型原则

- 有明确专家偏好且能解释一致性 → 可考虑 AHP；
- 希望由样本离散程度形成客观权重 → 可考虑熵权/CRITIC 类方法，但“客观”不等于“正确”；
- 目标是相对理想方案的距离 → TOPSIS；
- 存在效率前沿的投入产出关系 → DEA；
- 强调群体效用与个体遗憾的折中 → VIKOR；
- 模糊等级/隶属关系有现实意义 → 模糊综合评价。

不要因为方法多就把 AHP、熵权、TOPSIS、灰色关联全部串联。

## 关键验证

- 指标方向和标准化是否改变结论；
- 权重 ± 合理范围扰动后 top-k 是否稳定；
- 删除高度重复指标后排序是否大幅变化；
- 与 equal-weight baseline 的差异来自哪里；
- 对极端样本/异常值是否过度敏感。

## 论文证据

最终排名通常适合表格；更有价值的图是权重—排名稳定性、方案得分构成或敏感性，而不是再画一张排序柱状图。

## 边界

综合得分是构造量，不自动具有绝对物理意义；相关性、权重和排名不能写成因果。若排名对权重极敏感，应把“结果不稳定”作为结论的一部分，而不是隐藏。
