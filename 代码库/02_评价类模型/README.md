# 02 评价类模型

> 面向国赛 C 题"打分 / 排序 / 分级 / 方案优选"类问题的 Python 模板库。
> 每个文件独立可运行，自带中文注释、示例数据和 `__main__` 演示，**改数据即用**。

## 一句话选型

- 有数据、要客观排序打分 -> **07 熵权 TOPSIS**（首选）或 01 TOPSIS + 02 熵权
- 无数据、靠专家经验定权 -> **03 AHP**
- 指标含大量定性/等级描述 -> **04 模糊综合评价**
- 样本少、信息不完全、看相关性 -> **05 灰色关联**
- 要分档分级（优良中差）且抗异常值 -> **06 秩和比 RSR**
- 多投入多产出、评"相对效率"（不预设权重）-> **08 DEA 数据包络分析**
- 要"稳健折中、不被单一指标绑架"的推荐解 -> **09 VIKOR**（与 TOPSIS 互补：TOPSIS 求最接近理想，VIKOR 求可接受折中）

## 文件清单与功能

| 文件 | 算法 | 功能简介 | 输出 |
|------|------|----------|------|
| `01_TOPSIS法.py` | TOPSIS 优劣解距离法 | 正向化+标准化后算到正/负理想解距离，得相对贴近度 | 贴近度 C、排名 |
| `02_熵权法.py` | 熵权法（客观赋权） | 按指标数据离散程度客观定权 | 各指标权重、信息熵 |
| `03_层次分析法AHP.py` | AHP（主观赋权） | 判断矩阵求权重+一致性检验，可含方案层 | 权重、CR、方案得分 |
| `04_模糊综合评价.py` | 模糊综合评价 | 隶属度矩阵+模糊合成算子，评定等级 | 等级向量、评定等级、综合得分 |
| `05_灰色关联分析.py` | 灰色关联分析 GRA | 与参考序列的几何相似度，关联度分析/综合评价 | 关联度、排名 |
| `06_秩和比RSR.py` | 秩和比 RSR | 编秩→RSR→Probit回归→分档 | RSR、修正RSR、分档、排名 |
| `07_熵权TOPSIS组合评价.py` | 熵权法 + TOPSIS | 客观定权+逼近理想解排序，含灵敏度分析 | 权重、贴近度 C、排名 |
| `08_DEA数据包络分析.py` | DEA-CCR（投入导向） | 多投入-多产出下算相对效率，无需预设权重，判 DEA 有效 | 效率值 θ、是否有效、排名 |
| `09_VIKOR折中排序.py` | VIKOR 折中妥协排序 | 权衡"群体效益 S"与"个体最大遗憾 R"给折中解，带两条可接受性检验 | S/R/Q 值、排名、折中解判断 |

> **DEA 与其它评价法的区别**：TOPSIS/熵权/AHP 都要先定权重再综合打分；DEA 不预设权重，
> 由线性规划为每个决策单元找最有利权重算"投入产出效率"，特别适合"效率/绩效评估"类
> （医院、企业、区域、网点）。需要能把指标分成**投入**（越小越优）和**产出**（越大越优）两类。

## 核心参数与调参建议

### 指标正向化类型（01/02/05/07 通用）
所有评价前都要把指标统一成"越大越好"。`indicator_types` 每个指标取：

| 类型 | 含义 | 示例 | 处理方式 |
|------|------|------|----------|
| `max` | 极大型，越大越好 | 收益、质量分 | 不变 |
| `min` | 极小型，越小越好 | 成本、污染、死亡率 | `max(x)-x` 或 `1/x` |
| `mid` | 中间型，越接近目标越好 | pH、满意度目标值 | 需在 `best_values` 给目标值 |
| `range` | 区间型，落在区间内最好 | 体温、合格区间 | 需在 `best_values` 给 `[下界,上界]` |

### AHP 判断矩阵尺度（03）
用 **1~9 标度** 两两比较：1=同等，3=稍重要，5=明显，7=强烈，9=极端，2/4/6/8 为中间值，反向取倒数。
- 一致性检验：`CR = CI/RI < 0.1` 才通过；不通过要调整判断矩阵。
- 阶数建议 ≤ 9，超过难通过一致性；> 15 无 RI 值无法检验。
- 权重算法 `algorithm`：`comprehensive`（三法平均，默认最稳）/`eigen`（特征值法，经典）/`arithmetic`/`geometric`。

### 模糊评价算子选择（04）
| 算子 | 名称 | 特点 | 何时用 |
|------|------|------|--------|
| `M(*,+)` | 加权平均型 | 利用全部信息，结果平滑 | **默认首选**，指标都重要 |
| `M(∧,∨)` | 主因素决定型 | 只由主因素决定，信息损失大 | 单一指标起决定作用 |
| `M(*,∨)` | 主因素突出型 | 突出主因素兼顾其他 | 主因素为主、其余为辅 |

隶属函数用梯形/三角型（`build_membership`），等级节点 `levels` 升序设定，等级分值 `level_scores` 用于折算综合得分。

### 灰色关联分辨系数 ρ（05）
默认 `rho=0.5`。ρ 越小分辨力越强、关联系数差异被放大；建议在 0.1~0.5 做灵敏度分析。

### 秩和比 RSR（06）
- `full_rank`：`False` 非整秩（按数值线性插值编秩，默认，保留间距信息）/ `True` 整秩（平均秩次，样本大时用）。
- `threshold`：分档的 Probit 阈值，`[2,4,6,8]` 分 3 档，`[2,4,6,8,10]` 分 4 档等。
- 成本型指标先手动正向化（如取倒数）再传入。

## 主观赋权 vs 客观赋权 对比选择

| 维度 | 主观赋权（AHP） | 客观赋权（熵权法） |
|------|----------------|--------------------|
| 依据 | 专家经验/两两比较 | 数据本身离散程度 |
| 优点 | 反映决策偏好，适合无数据 | 客观、可复现、少被质疑 |
| 缺点 | 主观性强、易被评委质疑 | 忽略实际重要性，可能反直觉 |
| 适用 | 指标少、有专家经验、数据缺 | 有充足样本数据 |

**竞赛建议**：数据充足时优先客观（熵权 TOPSIS，见 07）；数据不足或需体现决策偏好用 AHP；
追求稳健可做 **组合赋权**（如 `w = α·w_AHP + (1-α)·w_熵权`，α 取 0.5），并对 α 做灵敏度分析写进论文。

## 适用的 C 题场景

- **对象综合排序/评级**：企业信贷评级（2020C）、地区/供应商/方案优劣排序 -> 07 / 01
- **确定指标权重**（作为后续优化/评价的输入）-> 02（客观）/ 03（主观）
- **定性指标为主的评价**：满意度、质量等级、风险等级 -> 04
- **小样本、找主要影响因素**：影响因素与目标的关联强弱 -> 05
- **分档分级评价**：把对象分成优良中差若干档 -> 06

## 输入输出格式约定

- 输入：数据矩阵 `X` 形状 `(n, m)`，行=对象、列=指标（numpy 数组或 pandas DataFrame）。
- AHP 输入为判断矩阵（正互反方阵）；RSR 输入为 DataFrame。
- 输出：权重向量（02/03）、贴近度/得分 + 排名（01/05/07）、等级向量（04）、分档表（06）。
- 所有文件 UTF-8 编码，直接 `python 文件名.py` 即可看到示例结果。

## 如何换成国赛附件数据

国赛数据通过题目附件（`.csv` / `.xlsx`）给出。每个模板的 `if __name__ == '__main__':` 里都有一段自造的**示例数据**用于演示，比赛时把它换成读取你自己附件的代码即可。通用三步：

1. **找示例数据**：打开目标 `.py`，翻到文件末尾 `if __name__ == '__main__':`，里面有醒目的 `👉 用你自己的国赛附件数据` 注释块，紧跟其后的就是【示例数据】。
2. **注释掉示例**：选中【示例数据】整段按 `Ctrl+/` 注释掉。
3. **换 read_csv 并对齐变量名**：取消注释注释块里给的模板代码，把 `pd.read_csv('附件1.csv', encoding='gbk')` 改成你的附件文件名，再按提示把列名换成你附件里的真实列名——注释块用的变量名（如 `data`、`objects`、`indicators`）已和该模板后续代码完全一致，改完即可运行。

评价类模型要特别注意两个参数按自己的指标改：

- **`indicator_types`**：长度=指标个数，逐个标注每个指标的类型 `max`（极大/越大越好，如收益）、`min`（极小/越小越好，如成本、死亡率）、`mid`（中间型/越接近目标越好，如 pH）、`range`（区间型/落在区间最好）。顺序必须和你取列的顺序一致。
- **`best_values`**：只有 `mid` / `range` 型指标才需要，是一个字典，**键为该指标的列索引（从 0 起）**，值为目标值（`mid`）或 `[下界, 上界]`（`range`）。例如第 3 列是中间型、目标 85，就写 `best_values = {3: 85}`。
- 另外：`01/02/05/07` 内置了正向化，可直接传原始数据；`06 秩和比 RSR` 需先手动把成本型指标正向化（如取倒数）；`03 AHP` 输入的是你按 1~9 标度自填的判断矩阵而非原始指标数据；`04 模糊评价` 可传专家隶属度矩阵或由连续指标值自动构造。

完整的读取姿势、乱码/Excel/多表/中文表头等各种坑，详见 `01_数据预处理与可视化/00_CSV数据导入完全指南.py`（可直接运行看演示）。
