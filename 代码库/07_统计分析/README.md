# 07 统计分析与推断

> 本目录用于描述数据、检验差异、估计关系和不确定性。统计方法的质量取决于**研究问题、观测单位、抽样/分组结构、效应大小和假设条件**，不取决于 p 值数量。

## 方法地图

描述统计/分布诊断、参数与非参数检验、ANOVA、相关分析、PCA/因子、趋势/秩相关、关联规则和贝叶斯回归均只是候选工具。先定义统计问题，再选方法。

## 先明确研究设计

- 观测单位是什么；
- 独立、配对、重复测量还是时间/空间相关；
- 连续、等级、计数或类别变量；
- 目标是差异、关联、预测还是解释；
- 实际关心的效应大小是什么。

## 结论优先级

```text
效应方向和大小
→ 不确定性区间
→ 稳健性/替代方法
→ p 值
```

`p<0.05` 不等于效果大或有实际意义；`p>=0.05` 不等于两组完全相同。

## 假设与替代

正态性、方差结构和独立性检查应服务具体方法。不要把“先做正态检验，p<0.05 就全部改非参数”当作机械流程。必要时比较参数/非参数、classical/robust 或 bootstrap/Bayesian interval。

## 多重比较与选择偏差

同时检验很多变量或组别时，应控制 FWER/FDR 或明确探索性属性。禁止只挑显著结果写进论文。

## 相关与降维边界

- 相关不自动等于因果；
- PCA 是方差压缩，不自动等于综合评价；
- 因子命名必须由载荷和现实含义共同支持；
- Granger 更接近时间预测信息，不自动等于机制因果。

## 论文证据

优先报告 effect + interval + 实际意义；图表展示分布、关系和区间。避免一页 p 值表和“显著/不显著”标签替代解释。

## 回退

如果样本量、独立性或测量质量不足以支持强结论，应缩小措辞或改成描述/探索性分析，而不是用更复杂统计模型掩盖数据限制。
