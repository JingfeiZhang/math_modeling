# 数学建模国赛 · 编程手算法代码库

> 面向全国大学生数学建模竞赛（国赛）**C 题**的编程手速查代码库。
> 所有代码为 **Python 独立可运行模板**：每个文件自带中文注释、示例数据和 `__main__` 演示，比赛时**改参数即用**。

## 使用方式

1. **先看这个**：[`01_数据预处理与可视化/00_CSV数据导入完全指南.py`](01_数据预处理与可视化/00_CSV数据导入完全指南.py) —— 讲透如何把国赛附件 CSV/Excel 读进来、选列取行、处理中文编码/缺失值/日期列。
2. 按"题目需要什么"到对应大类文件夹找算法。
3. 打开该类的 `README.md`，看**功能简介 / 适用场景 / 核心参数与调参建议**，定位到具体 `.py`。
4. 复制 `.py`，找到 `if __name__=='__main__':` 里的**【示例数据】**，按其正上方的 **👉 用你自己的数据** 注释块，把示例换成读你自己的附件（改文件名和列名即可），跑 `python xxx.py` 验证，再改参数。
5. **交卷前必看**：[`00_国赛合规与交付自检清单.md`](00_国赛合规与交付自检清单.md) —— 2026 国赛 AI 新规红线、AI 使用声明四字段、摘要/页数/三大检验等硬性规范，逐条打勾自查。

> **数据怎么导入？** 每个模板的示例数据上方都有一段 `👉 用你自己的国赛附件数据` 注释，直接照着改文件名/列名。完整说明见上面第 1 条的导入指南。

> **⚙️ 开赛第 0 步（3 分钟，别跳）**：先跑 `PYTHONIOENCODING=utf-8 python _run_all_tests.py` 确认整库能跑（期望 68/68）。conda/pip 会悄悄升级库导致模板报错，别等出结果时才发现。
> - 一键还原已验证环境：`pip install -r requirements.txt`（冻结了实测可跑的版本）
> - 报错照《[_环境与版本排错速查.md](_环境与版本排错速查.md)》对号入座，几分钟能修
> - 用 `~/miniconda3/python.exe`（Python 3.12.9），Windows 控制台务必前缀 `PYTHONIOENCODING=utf-8` 防中文乱码

## 国赛 C 题选题速查（历年规律）

C 题是**数据分析驱动**的应用题，题面给一批真实数据（CSV/Excel），通常 3~4 问，套路高度稳定：

| 年份 | 题目 | 核心方法（对应本库分类） |
|------|------|--------------------------|
| 2020 | 中小微企业信贷决策 | 评价(02) + 规划优化(05) |
| 2021 | 生产企业原材料订购与运输 | 预测(03) + 规划/智能优化(05,06) |
| 2022 | 古代玻璃制品成分分析 | 分类判别/聚类(04) + 统计检验(07) |
| 2023 | 蔬菜类商品自动定价与补货 | 预测(03) + 规划优化(05) |
| 2024 | 农作物种植策略 | 多目标规划(05) + 蒙特卡洛/NSGA-II(05,06) |
| 2025 | （随机森林类数据挖掘） | 预测/分类(03,04) + 特征分析(07) |

**通用解题流水线**：
```
数据预处理(01) → 探索/统计分析(07) → [预测(03) 或 分类聚类(04) 或 评价(02) 或 图论(08) 或 机理(09)]
→ 建立优化模型(05) → 求解(05精确解 / 06启发式) → 模型检验(10：误差/灵敏度/稳健性) → 可视化(01)
```
> 每个小问都要走完"建立→求解→**检验**→结果分析"闭环；想冲创新分可用组合模型(11)。检验(10)是 2026 自查表硬性要求，别漏。
