# 10 模型检验

> ⚠️ **2026 国赛 AI 自查表明确要求：论文必须包含误差分析、灵敏度分析、稳健性分析三大检验**（缺失即扣分）。本目录正是对齐该要求，给编程手做“建模→求解→**检验**→结果分析”闭环里的检验环。

C 题任何一个模型（预测/评价/优化/分类）建完、求出结果后，都要回答三个问题：
1. **准不准**？——误差分析（`01`）
2. **对参数假设敏不敏感**？——灵敏度分析（`02`）
3. **抗不抗干扰、换个数据/模型还稳不稳**？——稳健性分析（`03`）

外加两个进阶检验：模型**泛化**能力（`04` 交叉验证）与回归**残差假设**（`05` 假设检验）。

## 三大必备检验（自查表硬性要求）

| 检验 | 回答什么 | 本目录文件 |
|------|----------|-----------|
| **误差分析** | 模型预测与真实值差多少（R²/RMSE/MAPE…） | `01_误差分析与拟合优度.py` |
| **灵敏度分析** | 关键参数变动时结论稳不稳、哪个参数最关键 | `02_灵敏度分析.py` |
| **稳健性分析** | 数据加噪声/重采样/换模型后结论是否可靠 | `03_稳健性分析.py` |

## 文件总览

| 文件 | 用于 | 何时用 |
|------|------|--------|
| `01_误差分析与拟合优度.py` | 全套误差指标 + 残差/QQ/真实vs预测四联图 | **所有回归/预测模型**建完就用 |
| `02_灵敏度分析.py` | 单参数±10/20/30%扰动、龙卷风图、敏感度曲线、弹性系数 | **优化/评价/经济类**模型，说明参数影响 |
| `03_稳健性分析.py` | 噪声注入 + Bootstrap重采样 + 同类模型对比 | 需论证结论抗干扰、可靠时 |
| `04_交叉验证与泛化检验.py` | K折/留一法/学习曲线，判过拟合欠拟合 | **分类/回归/机器学习**模型选型与泛化评估 |
| `05_残差诊断与假设检验.py` | 正态性/方差齐性/独立性/异方差 + 判定建议 | **回归/时间序列**模型的假设合法性检验 |

## 各文件关键函数与入参

### 01 误差分析与拟合优度
- **核心接口**：`error_metrics(y_true, y_pred, n_params)` 返回全套指标 dict；`print_error_report(...)` 打印带评级的报告；`plot_diagnostics(y_true, y_pred)` 画四联图。
- **入参**：`y_true` 真实值、`y_pred` 模型预测值（等长一维）；`n_params` 自变量个数（算调整 R² 用）。
- **看什么**：R²/调整R²越接近1越好；残差图应随机无趋势；Q-Q 图点贴近直线说明残差近似正态；真实vs预测点贴对角线越好。

### 02 灵敏度分析
- **核心接口**：`oat_sensitivity(model_func, base_params)` 单参数扰动；`local_sensitivity_coef(...)` 弹性系数；`plot_tornado(...)` 龙卷风图；`plot_sensitivity_curves(...)` 敏感度曲线。
- **入参**：`model_func` 是 `f(**params) -> 标量` 的模型函数；`base_params` 是各参数基准值 dict。`perturb_ratios` 默认 ±10/20/30%。
- **看什么**：龙卷风图里条越长的参数越敏感；弹性系数 |S| 越大越敏感（>0 正相关，<0 负相关）。

### 03 稳健性分析
- **核心接口**：`noise_robustness(X, y)` 噪声注入；`bootstrap_robustness(X, y)` 自助重采样；`model_comparison_robustness(X, y)` 多模型对比。
- **入参**：`X` 特征矩阵 (n, k)、`y` 目标一维；可选 `fit_predict_func=f(X_train, y_train, X_eval)->y_pred` 检验你自己的模型（默认线性回归）。
- **看什么**：噪声增大时 RMSE 上升/R²下降越慢越稳健；Bootstrap 的 R² 分布越集中（标准差/CV越小）越稳健。

### 04 交叉验证与泛化检验
- **核心接口**：`holdout_eval` 单次划分；`kfold_cv` K折（箱线图）；`loo_cv` 留一法；`plot_learning_curve` 学习曲线。
- **入参**：`X`、`y`；`task='reg'`（回归）或 `'clf'`（分类）；可选 `model=` 传自己的 sklearn 模型；`k` 折数。
- **看什么**：K折标准差小=稳定；学习曲线两线都低=欠拟合，训练高验证低间隙大=过拟合。

### 05 残差诊断与假设检验
- **核心接口**：`diagnose_residuals(y_true, y_pred, X=None)` 一站式四项检验+汇总表；也可分开调 `test_normality/test_homoscedasticity_levene/test_independence_dw/test_heteroscedasticity_bp`。
- **入参**：`y_true, y_pred`（或直接传 `residuals`）；`X` 自变量矩阵（做 Breusch-Pagan 异方差检验用，可不给）。
- **看什么**：每项给“通过/未通过(需改进)”判定与改进建议；正态性看 Shapiro p≥0.05，独立性看 DW≈2，方差齐性/异方差看 p≥0.05。

## 如何换成你的模型数据

所有文件的 `if __name__ == '__main__':` 里都有【示例数据】，正上方是 `👉` 替换说明。通用做法：

- **误差分析(01) / 残差诊断(05)**：只需两列——你模型的**真实值 `y_true`** 和**预测值 `y_pred`**。预测值来自你已建好的模型（`y_pred = model.predict(X)`）。
- **稳健性(03) / 交叉验证(04)**：需要**特征矩阵 `X`（n行×k列）** 和**目标 `y`**，和建模时用的一样。想检验自己的模型：
  - 03 传 `fit_predict_func`：`def my_fp(Xtr, ytr, Xev): m=你的模型(); m.fit(Xtr,ytr); return m.predict(Xev)`。
  - 04 直接 `model=你的sklearn模型(...)`，并设 `task='reg'/'clf'`。
- **灵敏度(02)**：把示例 `profit_model` 换成你的模型函数 `f(**params)->标量`；`base_params` 填参数基准值。sklearn 模型可包一层：`def f(x1,x2): return float(model.predict([[x1,x2]])[0])`。

数据读取（编码/选列/日期）详见 `01_数据预处理与可视化/00_CSV数据导入完全指南.py`。

## 建议使用顺序（论文检验小节）

```
建好模型求出结果
  → 01 误差分析（给误差表 + 拟合优度图）          [必做]
  → 05 残差诊断（回归/时序模型，验证假设合法）    [回归/时序建议做]
  → 04 交叉验证（机器学习/预测，证明不过拟合）    [ML模型建议做]
  → 02 灵敏度分析（关键参数对结论的影响）          [必做]
  → 03 稳健性分析（噪声/重采样/换模型仍稳定）      [必做]
```

## 依赖库

```bash
pip install numpy scipy scikit-learn statsmodels matplotlib   # 一般 Anaconda 自带
```

- Python 3.8+（本目录在 Python 3.12.9 / numpy 2.x / sklearn 1.6 / statsmodels 0.14 下测试通过）。
- 中文绘图统一设 `plt.rcParams['font.sans-serif']=['SimHei']`；因 SimHei 无“²”字形，图内标签用 `R2` 代替 `R²`（控制台仍显示 R²）。
- 各文件均把图保存为 PNG（无图形环境自动跳过绘图，计算不受影响）。
