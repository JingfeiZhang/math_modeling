## 交卷前 5 分钟自查卡（AI 初筛 vs 人工必查）

**核心原则：AI 当"格式/完整性初筛器"，你当"真实性与合规的最终裁判"。**
先让 AI 扫左栏客观项省时间 → 你复核 AI 结论（它会漏也会误报）→ 右栏判断/责任项**必须你亲自过**。

| ✅ 可让 AI 初筛（客观、数得清/找得到，你再复核） | ⚠️ 必须人工判断（涉及事实真相与责任，AI 不可信） |
|-----------------------------------------------|------------------------------------------------|
| 摘要字数 800-1000、是否单独一页不跨页 | **核心建模是否人工主导**（只有你知道，AI 判"像不像 AI 写"极不可靠） |
| 正文页数 20-32（最优 25-30） | **AI 使用声明是否真实完整**（你在哪步用了 AI、改了什么，只有你能交代） |
| 模型假设是否 4-6 条 | **数据是否真实**、有无造数据/私自新增题外数据 |
| 结构模块是否齐全（重述/假设/符号说明/检验/优缺点/参考文献…） | **参考文献/行业结论是否真实存在**（防 AI 编造） |
| 三大检验（误差/灵敏度/稳健性）是否都在 | **结果是否合常识、参数取值有无依据**（需懂本题背景判断） |
| 是否残留学校/姓名/队伍信息（匿名） | **图表数值是否与原始计算一致**（防前后不匹配） |
| 图表编号、公式编号、三线表格式是否统一 | **推导因果是否有依据**（防强行关联） |

> 🚫 **别做的事**：把"整篇论文+题目+这张自查表"一起喂给 AI，让它"自动判定你是否合规"当通过凭证。
> AI 判合规不可信（高假阳/假阴），而且这个动作本身就和"人工主导核心建模"抵触。合规的最终判断靠你自己对照官方要求。

## 一、2026 国赛 AI 使用红线（硬性，违反即违规）

- [ ] **人工主导核心建模**：模型构建、公式推导、机理分析、求解逻辑必须人工主导，不得有重度 AI 主导生成痕迹。
- [ ] **核心写作不堆 AI 套话**：摘要、建模分析、结果论述、结论禁止模板化文风、AI 通用套话、无个性化思考。
- [ ] **AI 声明真实**：全文实际 AI 使用与"AI 使用声明"一致，严禁瞒报、漏报、虚假声明、用途不符。
- [ ] **AI 内容经人工核验**：不得直接提交原生未修改、无场景适配的纯 AI 段落。
- [ ] **不造数据**：所有数据源自赛题原题，不虚构、不篡改、不私自新增题外数据、不改数据精度。
- [ ] **不编文献/结论**：参考文献、行业结论、仿真数据真实有效，无 AI 编造。
- [ ] **图表数值可追溯**：图/表/拟合/公式的数值与原始计算完全一致，不凭空造数造图。
- [ ] **因果有依据**：推导逻辑与因果关系有支撑，无强行关联。
- [ ] **匿名合规**：全文无学校、姓名、队伍、隐私信息。

## 二、AI 使用声明模板 —— 四个必填字段

官方《AI 工具使用详情》要求按「环节」逐项拆分，每项写清：

1. **AI 工具名称和版本**（例：ChatGPT(GPT-4)、DeepSeek(V3.1)、豆包(V3.5)——写明版本号）
2. **使用目的与环节**（例：问题二模型建立 / 论文撰写 / 问题三代码求解优化 / 结果分析）
3. **关键交互记录**：`Query`(原始提示词) + `Output`(AI 原始回复摘录)
4. **采纳和人工修改情况**（采纳了哪部分、人工怎么改、为什么改）

> 编程手要点：写代码用了 AI，就在"问题X代码求解"环节如实记 Query/Output，并说明你对代码做了哪些人工修改与验证。

## 三、写作规范（自查表五、六维度）

- [ ] **摘要**：单独一页、不跨页、800-1000 字，含【量化结果 + 核心模型 + 创新点】，无空泛套话。
- [ ] **结构完整**：题目·关键词·摘要·问题重述·问题分析·模型假设·符号说明·建模求解·结果分析·**模型检验**·优缺点·参考文献，一个不缺。
- [ ] **三大必备检验齐全**：**误差分析 + 灵敏度分析 + 稳健性分析**（→ 用 `10_模型检验/`）。缺失即扣分。
- [ ] **模型假设 4-6 条**，贴合题意、合理简化，无过度/无效/致命假设。
- [ ] **内容呼应**：摘要、结论、结果、建模过程相互呼应，无矛盾、无脱节、结论有支撑。
- [ ] **正文页数 20-32 页**（最优 25-30），尽量不超 30。
- [ ] **格式统一**：字体字号行距缩进统一，标题编号连续；三线表、图片高清、公式居中编号。

## 四、结果合理性（自查表四维度）

- [ ] 计算结果符合常识 / 行业规律 / 赛题背景，无异常数值。
- [ ] 求解方法与模型类型匹配（不误用）。
- [ ] 关键参数取值有依据（不随意赋值）——参数来源在文中交代清楚。

## 五、建模逻辑（自查表三维度）

- [ ] 精准匹配赛题背景与要求，无题意误读、条件遗漏。
- [ ] 建模假设/推导/求解自洽，无前后矛盾、逻辑断裂。
- [ ] **全子问题闭环**：每个小问都有建模、求解、回应，不漏题、不空答。
- [ ] 模型选型贴合本题，不盲目堆砌高阶/通用模板模型。
- [ ] 题目关键约束全部纳入建模。

## 六、五阶段建模工作流（提示词精华，供编程手对照）

1. **赛题结构化拆解**：表格化背景/子问题/已知/参数/约束/原理，每小问归类（机理/预测/评价/优化/统计/网络）。
2. **各小问建模**：创新只走三条正道——算法改进 / 跨领域迁移 / 多模型融合，**拒绝无意义套模型**。
3. **数据预处理**：写"免本地绝对路径、带异常捕获、可直接运行"的代码，并做**预处理前后双图对比**。
4. **每小问四模块闭环**：建立 → 求解 → **检验** → 结果分析，缺一不可（每模型建议 ≥10 个公式、3-5 条带依据假设、变量用三线表）。
5. **推进剩余小问**，保持全文风格与符号统一。
