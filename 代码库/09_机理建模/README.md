# 机理建模（微分方程 / 系统动力学）

面向国赛 C 题里"**能讲清楚变化规律**"的问题。机理建模不是先拿数据硬拟合，而是
**先根据物理/生物/经济规律写出系统随时间变化的方程（通常是微分方程），再用少量
数据标定可解释的参数**。它的最大优势：参数有明确含义、外推可靠、结论有说服力，
是区别于"纯数据挖掘"的加分思路。

## 一、文件清单

| 文件 | 模型 | 核心工具 | 演示例子 |
|------|------|----------|----------|
| `01_微分方程模型.py` | Logistic 增长 + 通用 ODE 参数拟合 | `scipy.solve_ivp` + `least_squares` | 从含噪 S 形数据反推增长率 r、承载力 K 并外推 |
| `02_系统动力学SD.py` | SIR 传染病三仓室（存量-流量） | `scipy.odeint` | 疫情 S/I/R 曲线、感染峰值、参数敏感性 |

两个脚本都是 UTF-8、全中文注释、自带示例数据 + `__main__` 演示 + 存图，改参数即用。

## 二、什么时候用微分方程建模

出现下面这些信号，就该考虑机理/微分方程模型，而不是只上回归或机器学习：

- 题目关心**某个量随时间如何变化**（增长、衰减、消耗、传播、蓄积）；
- 你能说清"**变化率**取决于当前状态"——例如"增长速度正比于现有数量、又受上限约束"；
- 系统里有**存量**（累积的量：人口、库存、浓度、资金）和改变它的**流量**（速率）；
- 数据点不多，但背后规律清楚，需要**可解释、可外推**的模型。

对照：数据波动杂乱、说不清机理、只想拟合预测 → 用 03 预测类（回归/ARIMA/树模型）。

## 三、参数如何标定（本目录的关键能力）

机理模型 = 结构（方程形式）+ 参数（少量可解释常数）。结构靠分析规律定，参数靠数据反推：

1. **先定结构**：按规律写出微分方程，如 Logistic `dN/dt = r·N·(1 − N/K)`。
2. **再标参数**：用最小二乘让"方程数值解"逼近"实测数据"，反推参数。
   `01_微分方程模型.py` 里的 `fit_ode_params()` 就是通用工具：传入右端函数 `rhs`、
   时间 `t_data`、观测 `y_data`、参数初值 `p0`，即可拟合任意 ODE 的参数并给出 R²。
3. **调参建议**：
   - 参数个数尽量少（1~3 个）且都有物理含义，避免过拟合；
   - 初值 `p0` 贴近量纲（承载力 K 取观测最大值的 1~2 倍，增长率 r 取 0.1~1 常收敛）；
   - 不收敛先查数据单调性/单位是否统一，再换初值；年份类时间建议减去起点变成 0,1,2…。
4. **做敏感性分析**：改动关键参数（如 SIR 的接触率 β），观察峰值/拐点如何移动，
   写进论文能显著加分（见 `02_系统动力学SD.py` 里 β 从 0.35→0.50 的对比）。

## 四、C 题应用举例

| 题目类型 | 机理建模怎么用 |
|----------|----------------|
| 有上限的增长（新品渗透率、用户数、种植产量趋势） | Logistic 模型定 K 与 r，预测饱和水平与到顶时间 |
| 资源消耗 / 库存演化 | 存量-流量：库存被销售流消耗、被补货流补充，找稳定区间与补货策略 |
| 传播 / 扩散（疫情、口碑、谣言） | SIR / SEIR 仓室模型，估计峰值、拐点、干预（降 β）效果 |
| 衰减过程（浓度、残留、折旧） | 一阶衰减 `dy/dt=-k·y`，标定衰减常数 k 并外推 |
| 多主体动态系统 | 系统动力学：多存量 + 反馈回路，模拟长期走势与情景对比 |

**建模流水线**：分析规律 → 写微分方程（画存量-流量图）→ 用附件数据标定参数
（`fit_ode_params`）→ 数值求解与外推 → 参数敏感性分析 + 可视化。

## 五、如何换成国赛附件数据

机理建模的数据接法**和别的类不一样**：不是喂 `X`(特征矩阵)+`y`(标签)，而是喂
**「时间序列 + 该量的观测值」**去反推微分方程参数。两个脚本 `__main__` 里示例数据
正上方都有 `👉` 注释块，按它改即可。分两种情况：

**情况 A：拟合微分方程参数（`01_微分方程模型.py`）** —— 附件是"一列时间 + 一列数值"

```python
import pandas as pd
df = pd.read_csv('附件1.csv', encoding='gbk')   # 乱码换 utf-8 / gb18030
df = df.sort_values('时间列')                    # 机理建模务必先按时间排序
t_data = df['时间列'].values.astype(float)       # 一维时间：0,1,2… 或年份
y_data = df['数值列'].values.astype(float)       # 一维观测：数量/浓度/销量/产量…
# 时间若是年份，整体减去起始年（如 2015）变成 0,1,2…，拟合更稳定
p0 = [0.3, float(np.max(y_data)) * 1.5]           # 初值：r≈0.3，K≈观测最大值的1.5倍
fit = fit_ode_params(logistic_rhs, t_data, y_data, p0=p0)
```
- 换成**别的机理方程**（一阶衰减 `dy/dt=-k·y`、饱和增长等）：只要把 `logistic_rhs`
  换成你自己写的右端函数 `rhs(y, t, *params)`，再给对应的初值 `p0`，`fit_ode_params`
  通用。参数个数尽量 1~3 个且有物理含义。

**情况 B：系统动力学仿真（`02_系统动力学SD.py`）** —— 附件用来**定初值和标参数**，不是直接读一列

```python
df = pd.read_csv('附件1.csv', encoding='gbk')
N  = df['总人口'].iloc[0]        # 存量总量
I0 = df['初始感染'].iloc[0]      # 初始存量之一
S0, R0 = N - I0, 0               # 其余存量按守恒关系算
# 接触率 beta、恢复率 gamma 两种定法：查资料给经验值，或借情况A的
# fit_ode_params 思路、把 sir_model 当 rhs 用实测感染曲线反推
```

**通用三步**：① 注释掉示例数据整段；② 取消注释 `👉` 块并改文件名/列名；
③ 运行看拟合参数、R²、外推图。更完整的读取技巧（多编码、日期解析、缺失值、多附件合并）见
[`../01_数据预处理与可视化/00_CSV数据导入完全指南.py`](../01_数据预处理与可视化/00_CSV数据导入完全指南.py)。

> ⚠️ 机理建模常见坑：**时间没排序**（结果全乱）、**年份没归零**（数值太大不收敛）、
> **参数初值离谱**（不收敛，先查数据单调性和单位）、**参数太多**（过拟合、失去可解释性）。
