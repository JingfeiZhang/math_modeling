# 09 机理建模

> 机理模型用于描述状态如何随时间、空间或相互作用演化。高质量机理建模先保证**机制、量纲、边界和参数可解释**，再考虑数值求解器。

## 方法地图

常微分方程、偏微分/离散近似、系统动力学、种群/传播/动力学模型等都应从题目机制出发，而不是因为“能写微分方程”就采用。

## 建模顺序

```text
状态变量与单位
→ 作用机制/守恒关系
→ 外生输入与决策量
→ 初值和边界
→ 参数来源
→ 方程/状态转移
→ 数值方法
→ 校准与验证
```

## 必查学术问题

- 每一项是否有现实含义和正确量纲；
- 参数能否从数据中辨识，是否存在多参数补偿；
- 初值/边界是否与题面一致；
- 极限情况下模型是否回到合理行为；
- 是否满足守恒、容量、非负或其他不变量；
- 数值步长变化是否改变主结论。

## 参数估计

说明参数来自题面、文献、拟合还是优化。拟合得到的参数不自动具有真实机制意义；若可辨识性弱，应报告范围或把结论限制在输出预测层面。

## 验证

优先：维度检查、边界/守恒、简单极限案例、观测数据校准、参数敏感性和场景外推边界。不要只用“拟合曲线很好”证明机理正确。

## 论文证据

核心状态轨迹、关键机制关系、参数区间和场景差异最有价值。复杂方程只保留定义模型含义的部分，标准数值算法无需大篇幅科普。
