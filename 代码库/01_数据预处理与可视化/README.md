# 01 数据预处理与可视化

> 本目录用于学习数据读取、诊断、预处理和探索性可视化。预处理不是固定流水线；只有会影响当前模型正确性或解释性的处理才应进入正式方案。

## 文件地图

| 文件 | 主要用途 |
|---|---|
| `00_CSV数据导入完全指南.py` | CSV/Excel 读取、编码、日期与多表接口示例 |
| `01_缺失值与异常值处理.py` | 缺失与异常诊断/处理示例 |
| `02_数据标准化与变换.py` | 标准化、稳健尺度和变量变换示例 |
| `03_相关性与共线性.py` | 相关结构与共线性诊断 |
| `04_常用可视化模板.py` | 基础探索图示例 |
| `05_竞赛级图表集.py` | 多种绘图 API 示例，仅供学习 |

## 高质量使用顺序

```text
确认观测单位/主键/时间/空间粒度
→ 检查错误值、重复、缺失和单位
→ 识别时间/组/空间结构与泄漏风险
→ 只做模型真正需要的变换
→ 保存处理前后样本变化和理由
→ 再进入 baseline
```

## 处理决策

### 缺失

先判断缺失比例、模式和业务含义。均值填补不是默认方案；时间数据、分组数据、结构性缺失应采用与数据生成机制匹配的方法，并记录处理比例。

### 异常

先区分录入错误与真实极端事件。极端需求、事故、天气冲击等可能正是题目关心的风险，不得为让分布“好看”直接删除。

### 标准化

距离模型、PCA、正则模型通常需要关注尺度；树模型通常不因尺度不同而需要标准化。处理应服务模型，而不是机械执行。

### 相关性

相关热力图只能帮助发现结构，不能证明因果；共线性处理应结合模型稳定性、解释目标和正则化，而不是按相关系数阈值机械删变量。

## 可视化分层

- **Exploratory**：理解数据，允许快速粗图；
- **Diagnostic**：判断模型风险，如 residual、missingness、group error；
- **Paper Evidence**：只能从当前项目真实 artifact 通过正式绘图流程生成。

`05_竞赛级图表集.py` 展示的是 API，不意味着 3D、小提琴、气泡等图“更高级”。正式图先回答 reader question，再选择最简单有效的图型。

## 必查风险

- 时间数据随机切分；
- scaler/imputer 在全数据拟合；
- target encoding 泄漏；
- 合表主键造成重复或丢行；
- 单位转换后未同步指标；
- 预处理前后样本量变化未记录。

## Formal 前

不要直接复用示例处理结果。将必要处理写入当前项目 runner，并保存数据版本、变换参数、处理比例、单位和训练/验证边界。
