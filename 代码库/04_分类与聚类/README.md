# 04 分类与聚类

面向国赛 **C 题**的分类判别与聚类分组算法模板库。每个 `.py` 独立可运行、中文注释、自带示例数据与 `__main__` 演示，比赛时**改数据 + 调参即用**。

```bash
# 直接跑（会弹出图并在同目录保存 PNG）
python 01_KMeans聚类.py
```

## 文件清单与核心信息

| 文件 | 算法 | 功能简介 | 核心参数与调参建议 |
|------|------|----------|--------------------|
| `01_KMeans聚类.py` | K均值聚类（无监督） | 肘部法则+轮廓系数选K、聚类、簇画像 | `n_clusters(K)`：肘部图拐点 + 轮廓系数最大处定 K；**必须标准化**；只适合球形等径簇 |
| `02_DBSCAN密度聚类.py` | 密度聚类（无监督） | k-距离图定eps、网格调参、**异常点识别**(label=-1) | `eps`：看 k-距离图陡增拐点；`min_samples`≈2×特征维数；不用预设簇数、能发现任意形状 |
| `03_层次聚类.py` | 凝聚层次聚类（无监督） | 树状图dendrogram、切割定簇数 | `n_clusters`：树状图最长竖线处横切；`linkage`：ward(最常用)/average/complete |
| `04_高斯混合GMM.py` | 高斯混合软聚类（无监督） | BIC选成分数、输出**隶属概率**、椭圆可视化 | `n_components`：BIC 最小处；`covariance_type`：full(默认最灵活)/tied/diag；簇呈椭圆时优于KMeans |
| `05_逻辑回归分类.py` | 逻辑回归（有监督） | 二/多分类、混淆矩阵、ROC/AUC、可解释系数 | `C`：正则化倒数，越小正则越强防过拟合；`penalty`：l1/l2；不平衡加`class_weight='balanced'` |
| `06_SVM支持向量机.py` | 支持向量机（有监督） | 核函数选择、GridSearch调参、决策边界 | `kernel`：rbf(首选)/linear/poly；`C`：控过拟合；`gamma`：控边界复杂度；**必须标准化** |
| `07_KNN与判别分析.py` | KNN + LDA/Fisher/QDA（有监督） | KNN选k、线性判别、二次判别、LDA降维投影 | KNN `k`：交叉验证选、取奇数、**必须标准化**；LDA假设各类协方差相同兼降维；差异大用QDA |
| `08_决策树与随机森林分类.py` | 决策树 + 随机森林（有监督） | 树可视化、OOB、**特征重要性**、网格搜索 | 决策树`max_depth`剪枝防过拟合；随机森林`n_estimators`(100~500)、`max_features='sqrt'`、`min_samples_leaf`；**无需标准化** |

## 分类评价指标（05~08 文件均含）

- **准确率 Accuracy**：整体预测对的比例（类别不平衡时会失真）
- **精确率 Precision**：预测为正中真正为正的比例（重视“误报代价”）
- **召回率 Recall**：真正为正中被找出的比例（重视“漏报代价”）
- **F1**：精确率与召回率的调和平均（不平衡数据首选综合指标）
- **混淆矩阵**：各类预测 vs 真实的交叉计数，看错分到哪一类
- 多分类用 `macro` 平均；二分类概率模型另给 **ROC 曲线 + AUC**

## 聚类评价指标（01~04 文件均含）

- **轮廓系数 Silhouette**（-1~1，越大越好）：样本与本簇的紧密度 vs 与最近邻簇的分离度
- **CH 指数 Calinski-Harabasz**（越大越好）：簇间离散 / 簇内离散
- **DB 指数 Davies-Bouldin**（越小越好）：簇内紧凑度与簇间距离之比
- KMeans 另有 **SSE（簇内平方和）** 用于肘部法则

## 分类 vs 聚类 vs 判别 怎么选

| 类型 | 有无标签 | 目的 | 本库文件 |
|------|---------|------|----------|
| **聚类** Clustering | 无标签（无监督） | 把样本自动分组，事先不知道分几类/每类含义 | 01 KMeans、02 DBSCAN、03 层次、04 GMM |
| **分类** Classification | 有标签（有监督） | 学习“特征→已知类别”映射，预测新样本类别 | 05 逻辑回归、06 SVM、07 KNN、08 树/森林 |
| **判别** Discriminant | 有标签（有监督） | 分类的统计学说法，强调建立判别函数并解释 | 07 LDA/Fisher/QDA（分类的一种） |

选择口诀：
- **不知道有几类、要探索性分组** → 聚类（先标准化，簇数用肘部/轮廓/BIC/树状图定）
- **有历史标签、要预测新样本类别** → 分类（先划分训练/测试集，看混淆矩阵和F1）
- **要可解释的判别规则或有监督降维** → LDA/Fisher 判别、逻辑回归系数、决策树规则
- **要异常点识别** → DBSCAN（label=-1）
- **要每个样本的归属概率** → GMM（软聚类）或逻辑回归/随机森林（predict_proba）

**典型组合（2022 C题玻璃思路）**：先对成分数据聚类/画树状图探索结构 → 再用有标签样本训练 SVM/LDA 判别模型 → 对未知样本判定玻璃类型。

## 输入输出格式

- **输入**：
  - 聚类（01~04）：特征矩阵 `X`，形状 `(样本数, 特征数)`，纯数值、无需标签。
  - 分类/判别（05~08）：特征矩阵 `X` + 标签向量 `y`，形状 `(样本数,)`。
  - 实战替换：`df = pd.read_csv('data.csv'); X = df[['列1','列2',...]].values; y = df['标签列'].values`
- **输出**：
  - 控制台打印评价指标、最优参数、簇画像/特征重要性。
  - 每个脚本在**自身目录**保存若干 PNG 图（选K图、聚类/分类结果、混淆矩阵、ROC、树状图、特征重要性等）。

## 如何换成国赛附件数据

每个 `.py` 的 `if __name__ == '__main__':` 里都有一段【示例数据】，正上方已加 `👉` 注释块教你替换。通用三步：

1. **注释掉**示例数据整段，取消注释 `👉` 块里的 `pd.read_csv(...)` 那几行。
2. **改文件名与列名**：把 `附件1.csv`、`指标1/特征1/标签列` 换成附件里的真实名称（读入乱码就把 `encoding='gbk'` 换成 `utf-8` 或 `gb18030`）。
3. 直接运行，看控制台指标与保存的 PNG 图。

- **聚类(01~04，无监督)**：只需特征矩阵 `X_raw = df[['指标1','指标2',...]].values`，**不需要标签 y**。簇数用肘部/轮廓/BIC/树状图定。
- **分类/判别(05~08，有监督)**：需要特征矩阵 + 类别标签列，`X = df[['特征1',...]].values`，`y = df['标签列'].values`。

更完整的读取技巧（多编码尝试、缺失值、类别列编码、多附件合并）见 `01_数据预处理与可视化/00_CSV数据导入完全指南.py`。

## 通用注意事项

1. **标准化**：KMeans/DBSCAN/GMM/SVM/KNN/LDA 依赖距离或尺度，**必须先标准化**（模板已内置 `StandardScaler`）；树模型（决策树/随机森林）不需要。
2. **训练/测试划分**：有监督模型用 `train_test_split(..., stratify=y)` 分层抽样，避免类别失衡；评价看**测试集**指标。
3. **类别不平衡**：优先看 F1/召回率而非准确率；可用 `class_weight='balanced'`。
4. **GridSearchCV 的 `n_jobs`**：模板设为 `1` 保证跨平台稳定，本机多核时可改 `-1` 提速。
