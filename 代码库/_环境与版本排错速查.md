> 本表把已踩过的坑和一眼定位方法列出来，照着改几分钟就能恢复。
>
> **验证环境的唯一动作**：`PYTHONIOENCODING=utf-8 python _run_all_tests.py`
> —— 全绿(68/68)说明整库可跑；红了看下面对号入座。

## 1. 报错 → 病因 → 改法 对号入座

| 报错关键词 | 病因（哪个库升级了） | 改法 |
|---|---|---|
| `fillna() got an unexpected keyword 'method'` | pandas 3.0 移除 `fillna(method=)` | 用 `df.ffill()` / `df.bfill()` 代替 `fillna(method='ffill'/'bfill')` |
| `Cannot interpret '<StringDtype...>' as a data type` | pandas 3.0 字符串默认 `str` dtype，patsy/statsmodels 不认 | 送进 `ols()/anova` 前把分类列 `df[c] = df[c].astype(object)`（**别再 `.astype(str)`**，会退回 str dtype） |
| `module 'matplotlib.cm' has no attribute 'get_cmap'` | matplotlib 3.9 移除 `plt.cm.get_cmap` | 改用 `plt.get_cmap('tab10', n)` |
| `Axes.boxplot() got an unexpected keyword 'labels'` | matplotlib 3.9 把 `labels=` 改名 | 用 `tick_labels=`（老版本兼容：`try tick_labels / except labels`） |
| `only 0-dimensional arrays can be converted to Python scalars` | numpy 2.x 禁止对非 0 维数组 `float()` | 用 `float(np.ravel(x)[0])` 取标量 |
| `ndtr() takes from 1 to 2 positional arguments but 3 were given`（`kstest` 里） | scipy 新版 `kstest(dist_name, args=...)` 传参变更 | 传**冻结分布的 cdf**：`stats.kstest(x, stats.norm(loc=m, scale=s).cdf)` |
| `LogisticRegression.__init__() got an unexpected keyword 'multi_class'` | sklearn 1.7+ 移除 `multi_class` | 删掉该参数（多分类已自动用 multinomial/softmax，二分类自动 OvR） |
| `check_array() got an unexpected keyword 'force_all_finite'`（`factor_analyzer` 里） | factor_analyzer 0.5.1 与 sklearn≥1.8 冲突且上游没修 | 别用 factor_analyzer；本库 `07/06_因子分析.py` 已改用 **statsmodels** 的 `multivariate.factor.Factor` |

## 2. 通用定位手法（表里没有的新报错）

1. **看 Traceback 最后一行**：`TypeError: X() got an unexpected keyword 'Y'` → 十有八九是某库把参数 `Y` 改名或删了。
2. **去官方文档搜当前版本的函数签名**（不是搜旧教程），看参数叫什么。常见套路：
   - 参数被**改名**（`labels`→`tick_labels`、`force_all_finite`→`ensure_all_finite`）；
   - 参数被**删除**（`multi_class`、`fillna(method=)`）→ 通常有等价替代函数；
   - 返回值**从标量变数组**（sko 的 `best_y`）→ `np.ravel(x)[0]` 兜底。
3. **别急着降级整个环境**：降 numpy/sklearn 会连累一大片。优先改调用代码；实在搞不定再 `pip install -r requirements.txt` 整体还原。
4. 改完**单跑那个文件**确认，再 `_run_all_tests.py` 全量回归，防止改出新问题。

## 3. 缺库不慌：本库的"优雅降级"设计

很多模板缺可选库也能跑核心（自动退回）：

| 缺的库 | 影响的模板 | 自动退回到 |
|---|---|---|
| xgboost | 05 预测类 | sklearn GBDT |
| scikit-opt | 06 智能优化 | 只是跳过 sko 对照演示，手写版照跑 |
| mlxtend | 07 FP-Growth | 手写 Apriori |
| tensorflow/keras | 03 LSTM | MLP 滑窗 |
| pmdarima | 02 ARIMA | 网格搜索 auto 定阶 |
| seaborn | 各处热力图 | matplotlib imshow |

所以**装不上某个库先别慌**，看它是不是可选项；核心算法基本都有纯 numpy/sklearn 的退路。
