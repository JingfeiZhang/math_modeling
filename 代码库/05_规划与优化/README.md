## 核心参数与建模建议

### 01 线性规划 `scipy.optimize.linprog`
- **一律最小化**：`linprog` 求 `min c^T x`。求最大化就把 `c` 取负（模板里 `maximize=True` 自动处理）。
- **约束矩阵写法**：
  - 不等式统一写成 `A_ub @ x <= b_ub`。遇到 `>=` 两边乘 −1，如 `3x+2y>=12` → `[-3,-2]·x <= -12`。
  - 等式写成 `A_eq @ x = b_eq`。
  - `bounds=[(lb,ub),...]`，非负写 `(0, None)`，无界写 `(None, None)`。
- **method**：默认 `'highs'`（scipy≥1.6，高性能，推荐）。老版本可用 `'simplex'`。
- **易错点**：变量若必须取整数，linprog **不支持**，四舍五入常不可行，请转 02。

### 02 整数/0-1 规划 `pulp`
- **安装**：`pip install pulp`（自带 CBC 求解器，开箱即用）。注意 pulp≥3.0 需 Python≥3.8；旧环境用 `pip install pulp==2.7.0`。
- **为何不用 scipy**：linprog 只解连续 LP，整数约束需分支定界，必须用 pulp/cvxpy/ortools。
- **建模三步**：`LpProblem(方向)` → `LpVariable(cat=...)` → `prob += 目标`、`prob += 约束`、`prob.solve()`。
- **变量类型 `cat`**：`'Continuous'`(连续) / `'Integer'`(整数) / `'Binary'`(0-1)。混合整数只需对不同变量给不同 cat。
- **求解静默**：`prob.solve(pulp.PULP_CBC_CMD(msg=0))` 关闭日志。
- 批量变量用 `LpVariable.dicts`；点积/求和用 `lpDot`、`lpSum`。

### 03 非线性规划 `scipy.optimize.minimize`
- **method 选择**：
  - `'SLSQP'`：序列二次规划，支持等式/不等式约束+边界，**最常用、速度快**。
  - `'trust-constr'`：信赖域内点法，支持约束，**更鲁棒**，适合较难/病态问题。
  - 无约束光滑：`'BFGS'`；无梯度：`'Nelder-Mead'`。
- **约束方向陷阱**：`constraints` 里 `'ineq'` 表示 **`fun(x) >= 0`**，`'eq'` 表示 `fun(x)==0`（与 linprog 的 `<=` 相反！写约束前先转成 `>=0`）。
- **多初值**：非凸问题 minimize 只保证**局部最优**，务必用多个随机初值分别求解取最好（模板 `solve_nlp_multistart`）。

### 04 多目标规划
- **先归一化**：各目标量纲不同，加权前用各目标单独最优值（或量级）归一化，否则大数目标主导。
- **线性加权法**：`min Σ w_i·f_i`，权重反映偏好；简单但对**非凸前沿会漏解**。
- **ε约束法**：只优化主目标，其余转约束 `f_j <= ε_j`；改变 ε 可**扫出完整帕累托前沿**（含非凸），推荐用于画前沿。
- **理想点法**：先求理想点 `f*`，再 `min ||f(x)-f*||`（`p=2` 欧氏 / `p=inf` 切比雪夫）。
- **帕累托前沿**：无支配解集合，供决策者权衡 trade-off。目标多/规模大时用 06 的 **NSGA-II**。

### 05 动态规划
- **建模关键**：写清 **状态定义** 与 **状态转移方程**（模板每个函数注释已给）。
- 用 DP 的前提：最优子结构 + 无后效性 + 重叠子问题。
- 背包容量、阶段需为**离散/整数**；连续变量不适合，改 01/03。
- 提供回溯（背包选了哪些、最短路具体路径），便于论文展示方案。

### 06 蒙特卡洛
- **样本数 N**：误差以 `O(1/√N)` 下降，与维度无关（高维积分优势）。N 越大越准越慢。
- **固定 `seed`**：保证论文结果可复现。
- **风险模拟是重点**：对不确定参数（产量、价格、需求）按分布抽样，输出**期望收益、标准差、亏损概率、VaR**，把确定性优化升级为**稳健/随机规划**——正是 2024 C 题处理不确定性的思路。

## 如何换成国赛附件数据

规划类问题的核心思路是 **「附件参数表 → 模型系数」**：附件里给的成本、利润、产量、需求、资源上限等列，正是目标函数系数与约束矩阵的来源。拿到附件后先 `pd.read_csv` 读进来，再把对应列填进模型：

```python
import pandas as pd
df = pd.read_csv('附件1.csv', encoding='gbk')   # 中文乱码就换 utf-8 / gb18030
```

各模板的「数据 → 模型系数」映射：

| 文件 | 附件列 → 模型系数 |
|------|-------------------|
| 01 LP | `c = df['利润'].values`（目标系数）；`A_ub` 由各资源消耗列转置得到；`b_ub = df['资源上限'].values`（约束右端） |
| 02 整数/0-1 | `values = df['价值']`、`weights = df['重量']`（背包）；指派成本矩阵用 `df.pivot(...)` 透视 |
| 03 NLP | 目标/约束函数里的参数（单价、成本系数）读成向量，在 `f(x)` 内引用；约束统一写成 `>=0` |
| 04 多目标 | 两个目标函数系数取自附件不同列，如 `cost=df['成本']`、`profit=df['收益']` |
| 05 DP | 物品价值/重量列、距离邻接矩阵、一维时间序列均可来自附件（背包容量须为整数） |
| 06 蒙特卡洛 | 用附件**历史数据估计分布参数**：`mu, sigma = df['单价'].mean(), df['单价'].std()`，再填进抽样分布 |

每个 `.py` 的 `if __name__=='__main__'` 里已在示例数据正上方标注了具体替换写法。完整的读取/选列/编码/缺失值处理见 [`../01_数据预处理与可视化/00_CSV数据导入完全指南.py`](../01_数据预处理与可视化/00_CSV数据导入完全指南.py)。

## 精确解 vs 启发式（怎么选）

| 情况 | 选择 |
|------|------|
| 线性、连续、规模不大 | **01 LP**（精确、最优保证） |
| 整数/0-1，规模中小（变量≲数百） | **02 pulp**（精确，分支定界） |
| 非线性、光滑、凸或近凸 | **03 minimize + 多初值** |
| 多目标、想要帕累托前沿 | **04**（ε约束扫前沿） |
| 阶段化决策、状态离散 | **05 DP** |
| 变量极多 / 强非凸 / 组合爆炸 / 复杂多目标 | 转 **[06 智能优化算法](../06_智能优化算法/)**（GA/PSO/SA/NSGA-II，近似最优、无最优保证） |
| 含随机/不确定参数 | **06 蒙特卡洛** 做风险评估，配合上面任一优化 |

一句话：**能用精确解（01–05）就用，规模爆炸或非凸卡住再上启发式（06）。** 不确定性用蒙特卡洛包在外层。

## 输入输出格式

| 文件 | 主要输入 | 输出 |
|------|---------|------|
| 01 | `c, A_ub, b_ub, A_eq, b_eq, bounds` | 最优解 `x`、最优目标值 |
| 02 | 价值/重量/容量、成本矩阵、约束系数 | 选中项/指派方案、最优目标值、求解状态 |
| 03 | 目标函数 `fun`、`bounds`、`constraints` | 最优解、最优值、是否收敛 |
| 04 | 目标函数列表 `objs`、权重/ε、`bounds` | 折中解、各目标值、帕累托前沿点集 |
| 05 | 背包(值/重/容量)、邻接矩阵、序列 | 最优值+回溯方案（路径/选中项/子序列） |
| 06 | 被积函数/目标函数、分布参数、样本数 N | 积分值/π、最优点、期望/风险/VaR |
