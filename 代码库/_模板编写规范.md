## 4. 其它硬性要求
- **禁止联网数据**：不得用 `seaborn.load_dataset()` / 在线 URL；示例数据用 numpy 随机或手写小数组。
- **禁止 numpy 2.0 已删除别名**：不用 `np.int/np.float/np.bool/np.NaN`；第三方库若用到，在 import 前打补丁 `if not hasattr(np,'int'): np.int=int`。
- **函数化**：核心算法封装成函数，`if __name__ == '__main__':` 里演示。
- **中文注释**：关键步骤、参数含义、如何调参都要有中文注释。
- **可运行**：跑完要 print 关键结果；画图 `plt.savefig(...)` 存 PNG（不 plt.show()）。
- **参数调优说明**：docstring 或注释里说明关键超参怎么调、对结果的影响。
