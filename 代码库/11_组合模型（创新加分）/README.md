# 组合模型（创新加分）

组合模型 = 把两个（或多个）模型各取所长拼起来，弥补单一模型的短板。它是国赛
C 题**创新性加分**的主要抓手之一，但要避免"为组合而组合"的无意义堆砌——每个组合
都应回答"**A 解决了什么、B 补上了 A 的哪块短板**"。

本目录给了 3 个**可直接跑通的轻量范例**（纯 numpy / sklearn，不依赖 tensorflow 等重库）：

| 文件 | 组合 | 所属类别 | 一句话思路 |
|------|------|----------|-----------|
| `01_灰色Markov预测.py` | 灰色 GM(1,1) + 马尔可夫链 | 预测 | GM 定趋势，Markov 用状态转移修正残差波动 |
| `02_GA_SA组合优化.py` | 遗传算法 + 模拟退火 | 优化 | GA 全局搜索防早熟，SA 局部精修提精度 |
| `03_XGBoost网格贝叶斯调参.py` | XGBoost + 网格/随机搜索 | 预测 | 强基模型 + 自动调参，"模型+搜索器"通用范式 |

> 需要 LSTM/CNN/DNN 等**重量级**深度学习组合案例（含题目 + 完整源代码），见根目录
> [`../../2025国赛创新型算法+源代码汇总！`](../../2025国赛创新型算法+源代码汇总！) 文件夹（预测类/评价类/优化类各若干组合案例的 docx）。

## 二、组合模型是加分点，但别"无意义套模型"

官方评审看重创新，但堆模型≠创新。参考官方提示的**三条正当创新方向**，组合应落在其一：

1. **算法改进**：针对单一算法的缺陷做改造。如 GA 易早熟 → 接 SA 局部精修（本目录 `02`）；
   GM 残差有系统性波动 → 用 Markov 修正（本目录 `01`）。
2. **跨领域迁移**：把 A 领域的成熟方法迁到 B 领域解决新问题，并说明为何适配。
3. **多模型融合**：不同模型抓不同规律再融合。如 ARIMA(线性) + LSTM(非线性)、
   小波(分频) + LSTM，或"基模型 + 自动调参器"（本目录 `03` 的 XGBoost + 搜索）。

**判断组合是否有意义的自检**：
- 能说清"A 的短板正好被 B 补上"吗？（补不上就是凑数）
- 组合后指标（RMSE/精度/最优值）确实优于各自单用吗？——**务必做对照实验**，
  把"单模型 vs 组合"的结果对比写进论文，这才是有说服力的创新，而非空喊"我们用了组合"。
- 复杂度是否与题目匹配？小样本别硬套深度学习组合，够用、可解释更重要。
