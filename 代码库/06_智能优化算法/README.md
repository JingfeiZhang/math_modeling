# 智能优化算法（启发式 / 元启发式）模板库

面向数学建模国赛的**大规模、非凸、多目标、组合优化**问题（TSP、排班、选址、路径规划、资源分配等）。
当问题规模大到精确算法（线性/整数规划）无法在有限时间求解，或目标函数非凸、不可导、带复杂约束时，用这类算法在**可接受时间内求出高质量近似解**。

每个算法均提供两个版本：
- **手写实现**：结构透明，便于按题目需求改造算子、约束、目标函数。
- **scikit-opt / scipy / pymoo 调用**：接口成熟，几行代码即可跑，比赛抢时间用。

所有脚本 UTF-8、全中文注释、自带示例 + `if __name__=='__main__'` 演示 + 收敛曲线/结果图。

## 二、核心参数与调参建议

### 遗传算法 GA
| 参数 | 含义 | 建议 |
|------|------|------|
| `size_pop` 种群大小 | 个体数量 | 50~200；大则搜索广但慢。必须偶数 |
| `max_iter` 迭代代数 | 进化轮数 | 200~1000，看收敛曲线是否平稳 |
| `prob_cross` 交叉率 | 交叉概率 | 0.6~0.9，偏大加快信息交换 |
| `prob_mut` 变异率 | 变异概率 | 0.01~0.2；连续问题偏小，TSP 可偏大 |

调参口诀：先调种群与代数保证收敛，再用交叉率控制探索、变异率防早熟。务必开启**精英保留**避免最优解丢失。

### 粒子群 PSO
| 参数 | 含义 | 建议 |
|------|------|------|
| `w` 惯性权重 | 保持原速度趋势 | 0.4~0.9；推荐从 0.9 线性降到 0.4（前探索后收敛） |
| `c1` 认知因子 | 飞向个体历史最优 | 1.5~2.0 |
| `c2` 社会因子 | 飞向群体历史最优 | 1.5~2.0，通常 c1≈c2 |
| `pop` 粒子数 | 群体规模 | 20~50 |

`w` 大→全局探索，`w` 小→局部开发。`c1>c2` 重个体经验（防早熟），`c2>c1` 重群体协作（收敛快）。

### 模拟退火 SA
| 参数 | 含义 | 建议 |
|------|------|------|
| `T0` 初始温度 | 初期接受劣解能力 | 取足够大，使初始接受概率≈1 |
| `T_min` 终止温度 | 停止阈值 | 1e-3 ~ 1e-8 |
| `alpha` 降温系数 | 每步降温比例 | 0.90~0.99，越接近 1 解越好但越慢 |
| `L` 链长 | 每温度迭代次数 | 越大越充分，常取变量数的若干倍 |

关键在于**慢降温**：alpha 越大、L 越大，越接近全局最优但耗时越长。

### 蚁群 ACO
| 参数 | 含义 | 建议 |
|------|------|------|
| `alpha` 信息素重要度 | 依赖历史经验程度 | 1 左右；过大易早熟 |
| `beta` 启发式重要度 | 依赖距离贪心程度 | 2~5 |
| `rho` 挥发系数 | 信息素遗忘速度 | 0.1~0.5；大则探索强、收敛慢 |
| `n_ant` 蚂蚁数 | 每轮解数量 | 取城市数附近 |

`alpha/beta` 平衡"经验 vs 贪心"，`rho` 平衡"探索 vs 收敛"。ACO 是 TSP 类组合优化的强项。

### 差分进化 DE
| 参数 | 含义 | 建议 |
|------|------|------|
| `F` 缩放因子 | 差分扰动幅度 | 0.4~0.9；大则探索强、收敛慢 |
| `CR` 交叉率 | 继承变异体比例 | 0.7~0.9；可分离问题用小、非可分离用大 |
| `size_pop` 种群 | 个体数 | 5~10 倍维度，≥4 |

DE 对**高维连续、非凸**问题鲁棒且参数少，是连续优化的首选之一。`scipy.optimize.differential_evolution` 无需额外装库，最稳妥。

### NSGA-II（多目标）
| 参数 | 含义 | 建议 |
|------|------|------|
| `pop_size` 种群 | 前沿分辨率 | 100~200，越大前沿越密 |
| `max_gen` 代数 | 迭代轮数 | 200~500 |
| 交叉/变异 | SBX + 多项式变异 | pymoo 中 SBX `eta=15`、变异 `eta=20` 为常用默认 |

两大机制：**非支配排序**保证收敛到前沿，**拥挤度距离**保证前沿分布均匀。

## 三、适用 C 题 / 竞赛场景

| 算法 | 典型场景 |
|------|----------|
| GA   | 排班、选址、装箱、组合选择、参数寻优；编码灵活，几乎万能 |
| PSO  | 连续参数标定、函数拟合、神经网络权重、控制参数优化 |
| SA   | TSP、排班、布局等组合优化；单点搜索，实现简单，跳出局部最优能力强 |
| ACO  | TSP、车辆路径 VRP、网络路由等**图上路径**类问题的专长 |
| DE   | 高维连续非凸优化、模型参数辨识、工程设计变量优化 |
| NSGA-II | 多目标权衡：如**2024 国赛 C 题**"最大化利润 + 最小化风险"，输出帕累托前沿供决策 |

**多目标问题识别**：题目要求同时优化两个及以上互相冲突的目标（利润↑与风险↓、成本↓与覆盖↑），且不便加权成单目标时，用 NSGA-II 给出帕累托前沿，再结合题意选折中解。

## 四、算法优劣对比与选择建议

| 算法 | 优点 | 缺点 | 适合 |
|------|------|------|------|
| GA   | 通用、编码灵活、易加约束 | 参数多、收敛偏慢 | 组合优化通用首选 |
| PSO  | 实现简单、收敛快、参数少 | 易早熟、主要用于连续 | 连续参数优化 |
| SA   | 实现极简、能跳出局部最优 | 单点搜索、降温慢才好 | 中小规模组合优化 |
| ACO  | 组合/图问题效果好、可并行 | 参数敏感、计算量大 | TSP/VRP/路由 |
| DE   | 高维连续鲁棒、参数少 | 不擅长离散/组合 | 高维连续非凸 |
| NSGA-II | 一次得整条前沿、分布均匀 | 计算量大、需定义支配 | 多目标权衡 |

**选择流程**：
1. **连续单目标** → 先试 DE（`scipy`）或 PSO；维度高、非凸优先 DE。
2. **组合/排列（TSP、排班、选址）** → GA 或 SA 起步；纯路径问题上 ACO。
3. **多目标** → NSGA-II，输出帕累托前沿。
4. 比赛策略：先用库版本（scikit-opt/scipy）快速跑出基线结果，再按题目约束改手写版本；多算法对比结果写进论文更有说服力。

## 如何换成国赛附件数据

智能优化算法的入口是**目标函数**（连续/多目标）或**距离矩阵**（TSP 类）。附件数据要么变成目标函数里的参数，要么变成城市坐标/距离矩阵：

```python
import pandas as pd
df = pd.read_csv('附件1.csv', encoding='gbk')   # 中文乱码就换 utf-8 / gb18030
```

| 文件 | 附件数据 → 算法入口 |
|------|--------------------|
| 01 GA / 02 PSO / 05 DE | 连续优化：目标函数里的系数（成本、需求等）读成向量，在 `func(x)` 内引用：`coef = df['系数'].values` |
| 01 GA / 03 SA / 04 ACO | TSP 类：城市坐标 `points = df[['x','y']].values` 再算距离矩阵；或直接读方阵 `dist_mat = pd.read_csv('距离矩阵.csv', index_col=0).values` |
| 06 NSGA-II | 多目标：两个目标函数的参数取自附件不同列，如 `profit=df['收益']`、`risk=df['风险']`，在 `evaluate(X)` 内组合 |

要点：**目标函数的参数（距离、成本、收益系数）几乎都来自附件**——先把相关列读成 numpy 向量/矩阵，再在目标函数里引用即可，无需改动算法本体。每个 `.py` 的主程序里已在示例数据正上方标注了具体替换写法。完整读取/编码/选列见 [`../01_数据预处理与可视化/00_CSV数据导入完全指南.py`](../01_数据预处理与可视化/00_CSV数据导入完全指南.py)。

## 五、与精确算法（05_规划求解）的关系

- **精确算法（线性规划 LP / 整数规划 IP / 分支定界）**：能保证**全局最优**，但要求模型可线性化，且规模大时（NP 难问题如大规模 TSP、整数变量多）求解时间爆炸。
- **智能优化算法（本目录）**：不保证最优，但对**非凸、非线性、大规模、组合**问题能在有限时间给出**高质量近似解**，且对目标函数形式几乎无要求（可为黑箱、不可导、含仿真）。

**竞赛用法**：
- 问题能写成 LP/MILP 且规模不大 → 优先用精确求解器（如 `05_规划求解` 中的 PuLP / Gurobi / `scipy.linprog`），结果最优、最有说服力。
- 规模大或非凸、难以建成标准规划模型 → 用启发式算法；可先用精确算法解小规模子问题做验证/对照。
- 两者结合（数学规划 + 启发式）常是获奖论文的加分点：例如用精确解给小算例、用启发式解大算例并对比 gap。
