## 使用前先证明“为什么不能更简单”

至少满足一种：

- 明显非凸且局部方法不稳定；
- 离散组合规模使精确求解在比赛预算内不可行；
- 目标/约束由黑箱仿真给出；
- 多目标需要广泛探索非支配解；
- 有精确/松弛 reference，但需要更快近似。

如果 LP/MILP/网络流/DP 可以清晰解决，不应先上元启发式。

## 公平 baseline

启发式至少与以下一种比较：

- rule/greedy；
- 小规模精确解；
- LP relaxation / lower bound；
- 单一局部搜索。

没有 reference 时只能声称“在有限搜索预算下得到可行候选”，不能声称全局最优。

## 必做验证

- 所有输出先检查约束可行性；
- 至少多个独立种子，报告分布而非最好一次；
- 固定统一函数评估预算，公平比较不同算法；
- 记录 best/median/worst 或均值与离散程度；
- 收敛轨迹用于诊断停滞，不单独证明模型正确；
- 超参数只在算法确有价值后再调。

## 算法选择

- 连续黑箱：DE/PSO 可作为候选；
- 组合编码：GA/SA 取决于邻域与编码；
- 路径型问题：ACO 只有在其结构真正匹配时考虑；
- 多目标：NSGA-II 适合构造候选非支配集，但仍需检查覆盖、可行性和推荐点稳定性。

算法名称不是创新。真正值得写的是约束处理、编码、搜索空间缩减、与题目结构匹配的邻域或 hybrid 设计，并用实验验证其增益。

## 论文证据

优先展示最终方案、与 reference 的 gap/差异、多种子稳定性和 Pareto trade-off。不要让一张漂亮的 convergence curve 替代解质量证据。

## 回退

若不同种子结果波动大、可行率低、对超参极敏感或与简单 baseline 无稳定差异，应回退或缩小结论。
