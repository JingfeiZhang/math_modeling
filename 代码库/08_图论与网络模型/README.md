## 各算法功能 / 何时用 / 关键参数

### 01 Dijkstra 单源最短路
- **做什么**：从一个源点出发，求到所有其他点的最短距离**和具体路径节点序列**。
- **C 题何时用**：给一张带权路网，问"某点到各点怎么走最近/最省"。**边权必须非负**
  （距离、耗时、正成本都行）；含负权改用 Bellman-Ford/SPFA。
- **关键参数**：
  - `start` 源节点编号；`directed` 有向/无向（单行道设 True）。
  - 手写版基于 `heapq` 优先队列，复杂度 `O((V+E)logV)`，稀疏图快；返回 `dist` 与 `paths`。
  - 库版 `nx.single_source_dijkstra`，一次返回距离与路径字典。
- **输出**：源点到各点距离、路径；PNG 高亮最短路径树。

### 02 Floyd 全源最短路
- **做什么**：一次算出**任意两点之间**的最短距离矩阵，可重建每对点的具体路径。
- **C 题何时用**：后续模型要用"所有点对距离"时（选址、网络中心度、距离型聚类），
  或点数不大（≲400）懒得多次跑 Dijkstra。**能处理负权边，但不能有负权环**（代码会报警）。
- **关键参数**：
  - `directed` 有无方向；核心是三重循环，**中转节点 `k` 必须在最外层**（改了就错）。
  - `nxt` 后继矩阵用于 `reconstruct_path` 重建具体路径。
  - 复杂度 `O(n^3)`，n 大慎用。
- **输出**：`(n,n)` 距离矩阵 + 关键路径；PNG 距离矩阵热力图（不可达格子灰色）。

### 03 最小生成树 MST（Prim / Kruskal）
- **做什么**：在连通无向带权图里，选一组边把所有点连通且**总权重最小**（n-1 条边、无环）。
- **C 题何时用**：**管网/供水/电网/光缆/道路铺设**，要"用最小总成本/里程连通所有站点"。
  Prim、Kruskal 结果总权重必然相同（具体边可能不同，存在多棵等权 MST）。
- **关键参数**：
  - **必须是无向图、且连通**（不连通只能得最小生成森林，代码会报警）。
  - Prim 从 `start` 生长，适合稠密图；Kruskal 边排序+并查集，适合稀疏图。
  - 库版 `nx.minimum_spanning_tree(algorithm='kruskal'/'prim'/'boruvka')`。
- **输出**：MST 边列表 + 总成本；PNG 高亮选中的铺设线路。

### 04 最大流 / 最小割
- **做什么**：带容量的**有向**网络里，求源点 s 到汇点 t 的最大流量；由**最大流最小割定理**，
  最大流 = 最小割容量，最小割那组边就是网络**瓶颈**。
- **C 题何时用**：**物流运力**（各路段有运力上限，问最多能运多少、瓶颈在哪）、
  网络/管道吞吐、二分图**指派/分配**（任务-资源匹配可转最大流）。
- **关键参数**：
  - `edges` 为**有向边** `(u, v, cap)`，`cap≥0`；`source`、`sink` 源汇点。
  - 无向边/双向路需正反各加一条。多源多汇：加"超级源/超级汇"连到各真实源/汇。
  - 库版 `nx.maximum_flow` + `nx.minimum_cut`；手写版为 Edmonds-Karp（BFS 增广）。
- **输出**：最大流值、各边实际流量、最小割两侧集合与被切边；PNG 标注"流量/容量"、饱和边红色。

## 如何换成国赛附件数据（以边表 CSV 为例）

图论题的附件几乎都是**边表**：每行一条边，通常三列 `起点, 终点, 权重`
（权重按题意是距离/耗时/成本/容量）。统一的读取套路——**先把节点名映射成 0..n-1 的整数编号**，
再生成 `edges` 列表：

```python
import pandas as pd
df = pd.read_csv('附件_路网.csv', encoding='gbk')   # 中文乱码就换 utf-8 / gb18030

# 1) 收集所有出现过的节点名，建立 名字→整数编号 的映射
names = sorted(set(df['起点']) | set(df['终点']))
idx = {name: k for k, name in enumerate(names)}
node_names = names                       # 反过来用编号取名字，画图/打印用

# 2) 生成边列表（算法都吃这个格式）
edges = [(idx[r['起点']], idx[r['终点']], float(r['权重']))
         for _, r in df.iterrows()]
n = len(names)
```

各文件的"边表 → 参数"对应：

| 文件 | 权重列含义 | 有向? | 额外要指定 |
|------|-----------|-------|-----------|
| 01 Dijkstra | 距离/耗时/成本（**非负**） | 单行道才 True | `start` 源点编号 `idx['配送中心']` |
| 02 Floyd | 距离/耗时/成本（可负、无负环） | 按题意 | 无（一次算全部点对） |
| 03 MST | 铺设成本/里程 | **必须无向** | 无（图需连通） |
| 04 最大流 | 容量/运力/带宽上限 | **必须有向** | `source`、`sink` 源汇点编号 |

每个 `.py` 的 `if __name__=='__main__'` 里，示例数据正上方都有 **👉 用你自己的数据** 注释块，
照着改文件名/列名即可。完整的读取/选列/编码/缺失值处理见
[`../01_数据预处理与可视化/00_CSV数据导入完全指南.py`](../01_数据预处理与可视化/00_CSV数据导入完全指南.py)。

## 算法选择对照表

| 你的问题 | 选择 |
|---------|------|
| 一个源点 → 各点最短路，边权非负 | **01 Dijkstra** |
| 含负权边（无负环）/ 需要所有点对距离矩阵 | **02 Floyd** |
| 边权有负、要单源最短路 | Bellman-Ford / SPFA（本库暂未收录，可用 `nx.bellman_ford_path`） |
| 用最小成本把所有点连通（铺网） | **03 MST**（Prim 稠密 / Kruskal 稀疏） |
| 源→汇最大通过量、找瓶颈、分配匹配 | **04 最大流最小割** |
| 带成本上限的最小费用运输 | 最小费用最大流 `nx.max_flow_min_cost`（Floyd/最大流的延伸） |
| 节点重要性/网络结构分析 | networkx 中心性 `nx.betweenness_centrality` 等 |

一句话：**单源非负→01，全源/负权→02，连通铺网→03，运力容量分配→04。** 数据都先转成边表。
