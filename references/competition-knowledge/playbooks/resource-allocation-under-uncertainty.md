# 不确定条件下资源配置战术手册

> 适用于预算、产能、库存、人力或设备分配同时面对需求、价格或供给波动的赛题。本手册只负责早期决策路径，不是模型结论来源。

## 触发与排除

触发：决策包含数量或是否选择，存在明确资源约束，至少一个关键参数在决策时未知，并要求兼顾收益、成本、满足率或风险。

排除：不确定参数没有任何范围、历史或情景依据；题目只要求比较既定方案；变量和约束核心关系高度非线性且无法在可信区间线性化。此时先做透明情景比较或低维非线性探针。

## 输入输出合同

建立变量账本：每个决策变量的含义、单位、连续/整数类型、上下界和作出时点；每个约束的业务来源、硬/软属性和缺口处理；每个不确定参数的名义值、范围/分布/情景来源和实现时点。

输出必须包含同一类分配方案、目标分解、最大约束违反、缺口、求解状态和运行时间。鲁棒/随机方案还需输出名义代价、样本外风险、违反率和保守性代价。

## 分阶段行动

**P1**：把题面翻译成变量账本、资源守恒和时间顺序；区分事前变量与事后补救变量。先判断不确定性属于概率、区间、语言模糊还是仅有有限情景。

**P2**：用单位收益排序、容量比例或业务优先级构造可修复的分配 baseline；再做名义 LP。若整数动作确实存在，另跑小规模 MILP 对照。

**P3a**：在基准、乐观、压力情景复算同一方案，确定是目标波动还是可行性崩溃。只选择一种升级：二阶段随机、预算鲁棒或透明情景方案。

**P3b**：比较名义、升级方案的成本-风险曲线；扰动需求/容量/价格和保护参数。若模型过慢，先收紧上界、减少场景或分块，不立即转无界元启发式。

## baseline 与升级

```text
规则分配 baseline
  -> 名义 LP
  -> 必要的 MILP
  -> 三情景压力测试
  -> 随机 / 鲁棒 / 模糊中的一种有依据升级
  -> 允许时加入补救或滚动动作
```

选择随机规划需要可辩护的分布或场景概率；选择鲁棒规划需要有业务依据的不确定集；选择模糊规划需要可解释的语言等级和隶属函数。依据不够时停在情景分析，不以复杂性掩盖假设缺口。

## 联合诊断

1. **可行性与守恒**：逐约束检查资源平衡、缺口、上界和单位，定位不可行冲突组。
2. **整数与上界价值**：比较 LP 松弛和 MILP 的方案、目标、gap；检查每个 Big-M 或连接上界的业务来源。
3. **样本外风险**：在留出情景报告期望损失、尾部损失、违反率和关键资源缺口，不能只看平均目标。
4. **保守性代价**：报告保护参数变化时名义成本与风险下降；若方案排序随单个参数翻转，结论必须条件化。

## 停止与回退

- 名义 LP 已给整数可行解且逻辑无变化：不升级 MILP。
- MILP 超时：保存最好可行解和 gap，收紧上界或分块；仍超时则回退 LP/规则方案。
- 分布无法稳定估计：回退历史留出情景或区间敏感性。
- 鲁棒解过度保守：使用预算保护、缩小有依据的集合或加入补救；仍失衡则报告成本-风险曲线而不选唯一方案。
- 隶属函数变化导致排序翻转：只提供偏好情景，不冻结唯一结论。

## Candidate 交接

至少交接：变量账本、单位、硬/软约束、baseline 规则、LP/MILP 版本、上界来源、求解状态、目标分解、最大违反、情景生成规则、随机种子、名义/留出指标、保护参数、保守性代价、回退原因和输出路径。正式数字必须在之后由 Formal 重跑产生。

## 禁止事项

- 禁止用拍脑袋概率、区间或隶属函数支撑唯一方案。
- 禁止把事后变量提前知道情景的结果当作可执行计划。
- 禁止把超时可行解描述为全局最优。
- 禁止跳过同输出 baseline 和约束审计。
- 禁止将资料卡、原 PDF、教材示例或本手册作为论文引文、claims 或发布附件。
