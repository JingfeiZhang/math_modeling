# CUMCM 学术化高质量论文表达手册

用于 P4–P5。目标是形成一篇压缩但完整的技术研究论文：问题清楚、模型有依据、证据可追溯、结果可解释、边界诚实、评委可快速阅读。

依据仓库 `corpus/reports/cumcm-c-writing-template-2021-2025.md` 对 2021–2025 官方展示 C 题论文的页面级总结，只迁移稳定论证规律，不复制文字或固定章节。

同时遵循 `academic-quality-standard.md`、`academic-modeling-and-writing.md` 与 `visual-evidence-quality.md`。

## 1. 整篇主线

研究问题 → 数据与假设 → 数学结构 → 模型选择依据 → 模型定义 → 求解/估计 → 主结果 → baseline/替代模型比较 → 验证与不确定性 → 现实意义 → 局限和边界。优秀论文的可迁移优势不是算法多，而是每问有闭环。

## 2. 标题

优先研究对象与核心任务；只有真正构成主线的方法才进入标题。避免算法名串联、泛化标题、自创缩写无实质贡献。

## 3. 摘要：第一轮完整答题

每问尽量包含对象/目标 → 核心方法 → 最重要定量结果或交付 → baseline/参考比较 → 验证 → 边界/意义。摘要不是算法目录，数字必须能在正文定位。

## 4. 问题重述

只保留研究对象/背景、题面给定数据/规则、每问交付、子问题接口。不复制大段题面，不提前介绍算法。

## 5. 问题分析：展示研究设计

每问说明数学对象、核心冲突、信息可得性、数据/机理结构、主要约束、不确定性、方法适配原因和跨问连接。不要写成“Q1 用 ARIMA，Q2 用 NSGA-II”。

## 6. 假设

少而必要。关键假设对应公式、现实理由和潜在影响。避免“忽略所有次要因素”“认为数据真实可靠”等空话。

## 7. 符号与单位

共享符号前置统一；局部符号在对应模型定义；关键变量给单位；同一符号跨问不改变含义。

## 8. 数据处理

正文只写会改变模型判断的处理：观测单位、缺失/异常、单位、关键派生量、训练边界和样本变化，不写 pandas 流水账。

## 9. 模型选择：证据驱动

baseline 能解决什么 → 暴露什么不足 → 主模型增加什么结构 → 为什么对应题目难点 → challenger/验证是否支持复杂度。标准算法只简洁说明适配原因，不写百科。

## 10. 模型建立：公式服务语义

保留核心关系、目标、约束、状态转移、关键指标、必要估计关系。每个关键公式后解释变量和现实含义。

## 11. 参数估计

说明参数来源、估计方法、范围、关键假设和可辨识性。弱可辨识时不把数值过度解释成真实机制。

## 12. 算法与求解

写数学求解逻辑：输入、初始化、核心步骤、约束处理、停止条件、输出；不写目录、日志、调试、文件路径。

## 13. 结果黄金结构

Headline result → baseline/参考比较 → 原因/机制 → 实际意义 → 不确定性/边界。不要只描述曲线形状。

## 14. 统计结果

优先效应大小 + 区间 + 实际意义，p 值辅助。相关、特征重要性、SHAP 不自动等于因果。

## 15. 预测结果

优先样本外表现、峰值/分组失败和区间质量，不以训练拟合代表预测。

## 16. 优化结果

重点是方案本身、可行性、相对 baseline 改善、资源/成本/服务权衡和压力场景。算法收敛只辅助。

## 17. 多目标与机理

多目标明确目标方向、搜索方式、覆盖范围、推荐点依据；固定权重只写给定偏好。机理除了拟合，还写量纲/边界/守恒/极限/参数敏感性，并区分“能拟合”与“机制被验证”。

## 18. 图、表、文字

Table 精确读数；Figure 趋势/分布/关系/不确定性/空间/网络/权衡；Text 少量关键数字；None 无新增信息。一项证据只展示一次最合适形式。

## 19. 图表叙事

图前说明为什么看，图后说明结果意味着什么。图注写对象、条件和比较，不只是“XX 图”。

## 20. 验证章节

不机械写“误差、灵敏度、稳健性”三节。只保留攻击主要失败风险的验证，并明确风险 → 如何验证 → 结果 → 是否改变结论。

## 21. 每问结尾

直接回答最终答案/方案、相比 baseline 的价值、可信依据、适用条件、向下一问传递什么。

## 22. 跨问一致性

前问输出到后问输入时说明误差/区间/场景是否传播；共享变量、单位和口径保持一致。

## 23. 模型评价：写 Discussion

优势只写证据支持的优势；局限写强假设、数据范围、参数敏感、未覆盖场景、近似求解、外推边界；改进要针对局限可执行。

## 24. 学术措辞边界

heuristic → 近似/有限预算；observational association → 关联；sampled scenario → 所选场景；fixed weight → 给定偏好；training fit → 拟合。无证据不升级措辞。

## 25. 文献

只引用真正支持机制、参数、方法、评价标准或外部事实的来源。展示论文只学习结构，不作为当前赛题证据。

## 26. 论文压缩

删教材算法介绍、重复题面、调参流水账、无关描述统计、重复图表、长代码、失败模型全过程；保留题意转化、关键假设、核心公式、baseline、主结果、关键验证、意义和边界。

## 27. 最终评委通读测试

评委只看摘要、问题分析、关键模型定义、主结果表图、每问结尾、模型评价，仍应能回答：每问解决什么、为什么选模型、关键结果、相比简单方案改善什么、为什么可信、有何实际意义、在哪里失效。
